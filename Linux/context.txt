NAME
        mtx-texworks - TeXworks Startup Script

SYNOPSIS
       mtxrun --script texworks [ OPTIONS ...  ] [ FILENAMES ]

DESCRIPTION
       TeXworks Startup Script

OPTIONS
       --start
              [--verbose]   start texworks

       --test report what will happen
