PR_GET_AUXV(2const)                                                                                                                       PR_GET_AUXV(2const)

NOME
       PR_GET_AUXV - obtém o vetor auxiliar

BIBLIOTECA
       Biblioteca C Padrão (libc, -lc)

SINOPSE
       #include <linux/prctl.h>  /* Definição das constantes PR_* */
       #include <sys/prctl.h>

       int prctl(size_t size;
                 PR_GET_AUXV, void auxv[size], unsigned long size, 0L, 0L);

DESCRIÇÃO
       Coloca o vetor auxiliar (auxv) no buffer apontado por auxv, cujo tamanho é dado por size.

       Se o buffer não for longo o suficiente para o vetor auxiliar completo, a cópia será truncada.

VALOR DE RETORNO
       Em caso de sucesso, esta chamada retorna o tamanho total do vetor auxiliar. Em caso de erro, -1 é retornado e errno é definido para indicar o erro.

ERROS
       EFAULT auxv é um endereço inválido.

PADRÕES
       Linux.

HISTÓRICO
       Linux 6.4.

VEJA TAMBÉM
       prctl(2)
