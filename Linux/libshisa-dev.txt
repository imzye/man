NAME
       shisa_strerror - API function

SYNOPSIS
       #include <shisa.h>

       const char * shisa_strerror(int err);

ARGUMENTS
       int err     Shisa error code.

DESCRIPTION
       Explains verbally an error status err.  The returned string can be used to compose a diagnostic message of benefit to a user.

RETURN VALUE
       Returns a pointer to a statically allocated string, containing a description of the error given as input argument.
