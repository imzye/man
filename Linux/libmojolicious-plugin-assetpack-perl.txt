NAME
       Mojolicious::Plugin::AssetPack::Pipe::Css - Minify CSS

DESCRIPTION
       Mojolicious::Plugin::AssetPack::Pipe::Css will minify your "css" assets if "minify" in Mojolicious::Plugin::AssetPack is true and the asset is not
       already minified.

       This module requires the optional module CSS::Minifier::XS to minify.

METHODS
   process
       See "process" in Mojolicious::Plugin::AssetPack::Pipe.

SEE ALSO
       Mojolicious::Plugin::AssetPack.
