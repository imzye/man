NAME
     fpm-scaffold - Generate project scaffolding for Fortran julienne

SYNOPSIS
     fpm-scaffold [OPTIONS] [PROJECT_NAME]

DESCRIPTION
     The  julienne scaffold command generates a new project directory with the necessary files and structure for a Fortran julienne project. This includes source directories, build configuration, and ex‐
     ample files.

OPTIONS
     -h, --help
            Show this help message and exit.

     -v, --version
            Show version information and exit.

     -t, --template TEMPLATE
            Specify a template to use for scaffolding (default: "basic").

     -d, --directory DIR
            Specify the output directory (default: current directory).

     -f, --force
            Overwrite existing files if they exist.

EXAMPLES
     Create a new project in the current directory:
            fpm scaffold my_project

     Create a project using a specific template:
            fpm scaffold -t advanced my_project

     Create a project in a specific directory:
            fpm scaffold -d ~/projects/ my_project

FILES
     The following files and directories are created by default:
            my_project/
                ├── src/
                │   ├── main.f90
                │   └── ...
                ├── test/
                │   └── ...
                ├── Makefile
                ├── README.md
                └── .gitignore
