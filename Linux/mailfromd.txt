NAME
       mfmodnew - creates a Mfmod Structure

SYNOPSIS
       mfmodnew [OPTIONS] MODNAME [DIR]

DESCRIPTION
       mfmodnew creates and bootstraps a new dynamically loaded module for mailfromd

       OPTIONS are:

       -C DIR Search for template files in DIR (default: /usr/share/mailfromd/mfmod)

       -e EMAIL
              Set author email address

       -q     Suppress informative messages.

       -h     Print this help text.
