NAME
       Data::Session::Serialize::JSON - A persistent session manager

Synopsis
       See Data::Session for details.

Description
       Data::Session::Serialize::JSON allows Data::Session to manipulate sessions with JSON.

       To use this module do this:

       o Specify a driver of type JSON as Data::Session -> new(type => '... serialize:JSON')

Case-sensitive Options
       See "Case-sensitive Options" in Data::Session for important information.

Method: new()
       Creates a new object of type Data::Session::Serialize::JSON.

       "new()" takes a hash of key/value pairs, some of which might mandatory. Further, some combinations might be mandatory.

       The keys are listed here in alphabetical order.

       They are lower-case because they are (also) method names, meaning they can be called to set or get the value at any time.

       o verbose => $integer
           Print to STDERR more or less information.

           Typical values are 0, 1 and 2.

           This key is normally passed in as Data::Session -> new(verbose => $integer).

           This key is optional.

Method: freeze($data)
       Returns $data frozen by JSON.

Method: thaw($data)
       Returns $data thawed by JSON.
