NAME
       perlmmc - lower-level wrapper to MMC from libcdio, the ISO 9660 library of the CD Input and Control package

SYNOPSIS
       This is fairly straight-forward wrapper around the MultiMedia commands from the C library libcdio. Although this is perfectly usable on its own, it is
       expected that the interfaces Device::Cdio::MMC or Device::Cdio::Device::MMC is what most people will want to use.

       There are various constants that are defined here.

METHODS

       This seems to be an artifact of SWIG.

       <http://www.gnu.org/software/libcdio> has documentation on libcdio including the a manual and the API via doxygen.
