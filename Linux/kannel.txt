NAME
       wmlsc - WMLScript compiler

SYNOPSIS
       wmlsc [-adlsv] file...

DESCRIPTION
       wmlsc compiles WMLScript source files into a binary version.  It is useful for testing WMLScript file correctness.

SEE ALSO
       wmlsdasm(1), kannel(8).
