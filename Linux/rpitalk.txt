NAME
     rpitalk-config - interactive configuration tool for RPITalk emulator

SYNOPSIS
     rpitalk-config

DESCRIPTION
     rpitalk-config is an interactive configuration script for the RPITalk hardware speech synthesizer emulator.

     It reads default values from /etc/rpitalk/emulator.conf and prompts the user to select:

            • which synthesizer to emulate (DECtalk or LiteTalk)

            • which serial port to use

            • the debug verbosity level

     After collecting user input, rpitalk-config updates the following configuration files while preserving comments:

            • /etc/rpitalk/emulator.conf

            • /etc/rpitalk/gadget.conf

     If the selected port is ttyGS0, USB gadget mode is enabled automatically in /etc/rpitalk/gadget.conf .  For other ports, gadget mode is disabled.

CONFIGURATION FILES
     /etc/rpitalk/emulator.conf
            Main configuration file for the emulator. The following keys are updated:

            emulate
                   Which synthesizer to emulate: dectlk or ltlk.

            port   Serial port device name (for example, ttyGS0 or ttyUSB0).

            debug  Debug verbosity level (0 to 3).

     /etc/rpitalk/gadget.conf
            USB gadget configuration file. The following keys are updated:

            ENABLE_GADGET
                   Set to 1 if the selected port is ttyGS0, otherwise 0.

            PRODUCT_ID
                   USB product ID corresponding to the selected emulation type.

            SERIAL
                   USB serial number string.

            PRODUCT
                   USB product description string.

INTERACTIVE OPERATION
     When run, the program:

            1. Reads defaults from /etc/rpitalk/emulator.conf .

            2. Prompts for an emulation type (1 = DECtalk, 2 = LiteTalk).

            3. Prompts for a serial port name.

            4. Prompts for a debug level (0 to 3).

            5. Writes the updated values to the configuration files.

EXAMPLES
     Run the configuration tool:

     rpitalk-config

FILES
     /etc/rpitalk/emulator.conf
            RPITalk emulator configuration file.

     /etc/rpitalk/gadget.conf
            RPITalk USB gadget configuration file.
