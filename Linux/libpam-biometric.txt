NAME
       bioctl - control tool for biometric device driver

SYNOPSIS
       biodrvctl

DESCRIPTION
       biodrvctl is a control tool for biometric device driver in the UKUI desktop.  It changes the status of biometric device driver.

        enable
              Enable biometric device driver.

        disable
              Disable biometric device driver.
