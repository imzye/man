NAME
       debiman-auxserver - serves HTTP redirects

SYNOPSIS
       debiman-auxserver [flag]

DESCRIPTION
       debiman-auxserver  loads an index of manpages generated by debiman(1) and serves HTTP redirects for paths which are not fully qualified. E.g., access‐
       ing /i3.1 results in being redirected to /stretch/i3-wm/i3.1.en.html.

OPTIONS
       Run debiman-auxserver --help for more details.
