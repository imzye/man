NAME
       Data::TableReader::Decoder::XLS - Access sheets/rows of a Microsoft Excel '97 workbook

VERSION
       version 0.021

DESCRIPTION
       See Data::TableReader::Decoder::Spreadsheet.  This subclass simply parses the input using an instance of Spreadsheet::ParseExcel.

CLASS METHODS
   default_xls_module
       Initializes @Data::TableReader::Decoder::XLS::default_xls_module to the first available module in the list of
       @Data::TableReader::Decoder::XLS::xls_probe_modules and returns the cached value every time afterward.

       Those variables can be modified as needed, if you have other XLS modules available.
