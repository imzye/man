NAME
     dclsysfont - display a gallery of available system fonts

SYNOPSIS
     dclsysfont [ options ]

DESCRIPTION
     dclsysfont is a utility program included in the GFD Dennou Club Library (DCL). It displays a visual list (gallery) of all system fonts detected by DCL.

     Unlike dclfontlist which only prints names to text output, dclsysfont renders sample text using each font in a graphics window, allowing users to verify how specific fonts look when used in DCL.

   Operation
     When executed, the program performs the following steps:

     1.  It scans the system for available fonts.

     2.  It interactively prompts the user to enter a Workstation ID number (e.g., 1 for X/GTK, 2 for PDF, etc., depending on the installation).

     3.  It opens the specified graphics workstation.

     4.  It draws a list of fonts, 10 per page. Each entry shows:

         • The internal font index number.

         • The font name (appended with 'Regular').

         • Sample text: "ABCabs012" followed by three Kanji characters ("留硫粒") to test multibyte rendering support.

     5.  Simultaneously, it prints the full name of each font to the standard output.

OPTIONS
     dclsysfont accepts standard DCL runtime parameters via the command line, though the Workstation ID must be provided interactively via standard input.

EXAMPLES
     To start the gallery viewer:

            $ dclsysfont
             WORKSTATION ID (I)  ? ;
             1

     (Enter 1 to select the default window system, usually X11 or GTK.)
