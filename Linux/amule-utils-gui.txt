NUME
       amulegui - Controlul programului aMule prin GUI

REZUMAT
       amulegui [-c <path>] [-geometry <geom>] [-o] [-r] [-s] [-t <num>]

       amulegui [-v]

       amulegui [-h]

DESCRIERE
       amulegui  este  un  program client și poate fi conectat la amule sau amuled prin EC. Puteți administra programul amule cu el. Asigură aproape aceleași
       funcțiuni ca amule, chiar dacă nucleul funcționează pe un alt computer.

       [ -c <path>, --config-dir=<path> ]
              Citește configurarea din <path> în schimb de acasă

       [ -geometry <geom> ]
              Configurează       geometria       aplicației.       <geom>        utilizează        același        format        ca        standard        X11
              apps:     [=][<width>{xX}<height>][{+-}<xoffset>{+-}<yoffset>]

       [ -o, --log-stdout ]
              Tipărește jurnalul de mesaje la stdout.

       [ -r, --reset-config ]
              Resetare configurări la valorile implicite.

       [ -s, --skip ]
              Omite dialogul de conectare.

       [ -t, --category=<num> ]
              Configurați categoria pentru link-urile eD2k trecute la <num>

       [ -h, --help ]
              Tipărește o scurtă descriere de utilizare.

       [ -v, --version ]
              Afișează numărul versiunii curente.
