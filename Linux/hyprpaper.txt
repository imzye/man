NAME
       hyprpaper - Wallpaper utility for Hyprland (and other wlroots-based compositors).

SYNOPSIS
       hyprpaper [arg [...]]

OPTIONS
       -h, --help
              Show command usage.

       -c, --config
              Specify config file to use

       --no-fractional, -n
              Disable fractional scaling support
