Name
       dawgdic-build - build a DAWG-based dictionary

Usage
       dawgdic-build [options] [lexicon-file [dictionary-file]]

Description
       dawgdic-build  reads sorted list of words from lexicon-file (or standard input), builds a DAWG dictionary and saves it to dictionary-file (or to stan‐
       dard output).

Options
       -h     Display help and exit.

       -t     Handle tab as separator.

       -g     Build dictionary with guide.

       -r     Build dictionary with ranked guide.

See also
       dawgdic-find(1)
