NAME
       mousam - graphical weather application

SYNOPSIS
       mousam [options]

DESCRIPTION
       mousam  is  a graphical weather application that displays current weather conditions and forecasts. The application provides a user-friendly interface
       with weather icons, temperature readings, and atmospheric data.

       mousam use the Open-Meteo.com datas.

       The application runs as a standalone graphical program and utilizes weather APIs to fetch real-time data based on user location or selected cities.

OPTIONS
       --help Show help message and exit

       --version
              Show program's version number and exit

       Note: Most configuration is done through the graphical interface.

FILES
       No persistent configuration files are used by this application.

SEE ALSO
       Project repository: https://github.com/amit9838/mousam

BUGS
       No known bugs at time of publication. For bug reports and feature requests, please use the issue tracker at the project GitHub repository.

NOTE
       To test the internet connection, mousam tries to connect to cloudflare DNS server, gnu.org and wikipedia.org.
