NAME
       ucat - unpack everything to standard output

SYNOPSIS
       ucat [OPTION]... [FILE]...

DESCRIPTION
       Uncompress multiple files contents to STDOUT.

OPTIONS
       -s     Show the list of supported formats

       -h     Show this help

       -v     More verbosity, to STDERR

       --version Show the tool version
