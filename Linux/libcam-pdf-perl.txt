NAME
       readpdf - Read a PDF document

SYNOPSIS
        readpdf [options] file.pdf

        Options:
          -d --decode         uncompress internal PDF components
          -p --pass           prompt for a user password if needed
          -v --verbose        print the internal representation of the PDF
          -h --help           verbose help message
          -V --version        print CAM::PDF version

DESCRIPTION
       Read a PDF document into memory and, optionally, output it's internal representation.  This is primarily useful for debugging, but it can also be a
       way to validate a PDF document.

SEE ALSO
       CAM::PDF

       rewritepdf
