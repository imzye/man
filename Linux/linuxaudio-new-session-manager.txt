NAME
       jackpatch - manual page for jackpatch Version 1.6.1

DESCRIPTION
       jackpatch - Remember and restore the JACK Audio Connection Kit Graph in NSM

       It is intended as module for the 'New Session Manager' and only communicates over OSC in an NSM-Session.

       It has limited standalone functionality for testing and debugging, such as:

   Usage:
       jackpatch [filename]
              Restore a snapshot from --save and monitor.

              jackpatch --help

OPTIONS
       --help Show this screen and exit

       --version
              Show version and exit

       --save Save current connection snapshot to file and exit
