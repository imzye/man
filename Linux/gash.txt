NAME
     gash - Guile As SHell, a POSIX-compatible shell

SYNOPSIS
     gash [OPTION]... [FILE]...
     gash [OPTION]...

OPTIONS
     -c, --command=STRING
            Evaluate STRING and exit

     -e, --errexit
            Exit upon error

     -h, --help
            Display this help

     -p, --parse
            Parse the shell script and print the parse tree

     -v, --version
            Display the version

     -x, --xtrace
            Print simple command trace
