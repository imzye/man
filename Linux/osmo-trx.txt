NAME
       OsmoTRX - osmo-trx-lms

DESCRIPTION
       OsmoTRX is a software-defined radio transceiver.

OPTIONS
       -h, --help
              This text

       -C, --config
              Filename The config file to use

       -V, --version
              Print the version of OsmoTRX

   VTY reference generation:
       --vty-ref-mode MODE
              VTY reference generation mode (e.g. 'expert').

       --vty-ref-xml
              Generate the VTY reference XML output and exit.
