NAME
     docker-credential-secretservice - store Docker credentials using the D-Bus Secret Service API

SYNOPSIS
     docker-credential-secretservice command

DESCRIPTION
     docker-credential-secretservice  is  a  credential helper for the Docker engine that uses the D-Bus Secret Service API as the credentials store.  It allows Docker to securely store and retrieve reg‐
     istry authentication credentials using a keyring service such as gnome-keyring or kwalletd.

COMMANDS
     store  Adds credentials to the keyring.  The payload in the standard input is a JSON document with ServerURL, Username and Secret.

     get    Retrieves credentials from the keyring.  The payload in the standard input is the raw value for the ServerURL.

     erase  Removes credentials from the keyring.  The payload in the standard input is the raw value for the ServerURL.

     list   Lists stored credentials.  There is no standard input payload.

     version
            Prints the version of the credential helper.

CONFIGURATION
     To configure Docker to use this credential helper, set the credsStore option in ~/.docker/config.json:

            {
              "credsStore": "secretservice"
            }
