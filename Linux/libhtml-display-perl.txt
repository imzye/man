NAME
       HTML::Display::Win32 - display an URL through the default application for HTML

SYNOPSIS
         my $browser = HTML::Display->new();
         $browser->display("<html><body><h1>Hello world!</h1></body></html>");

BUGS
       Currently does not work.

       Making it work will need either munging the tempfilename to become ".html", or looking through the registry whether we find a suitable application
       there.
