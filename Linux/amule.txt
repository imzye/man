NUME
       amule - client eMule p2p pentru toate platformele

REZUMAT
       amule [-c <path>] [-geometry <geom>] [-o] [-r] [-w <path>] [-d] [-i] [-t <num>] [eD2k-link]

       amule [-v]

       amule [-h]

DESCRIERE
       [ -c <path>, --config-dir=<path> ]
              Citește configurarea din <path> în schimb de acasă

       [ -geometry <geom> ]
              Configurează        geometria        aplicației.        <geom>        utilizează        același        format       ca       standard       X11
              apps:     [=][<width>{xX}<height>][{+-}<xoffset>{+-}<yoffset>]

       [ -o, --log-stdout ]
              Tipărește jurnalul de mesaje la stdout.

       [ -r, --reset-config ]
              Resetare configurări la valorile implicite.

       [ -w <path>, --use-amuleweb=<path> ]
              Specificați locația fișierului binar amuleweb la <path>.

       [ -d, --disable-fatal ]
              Nu manipula excepția fatală.

       [ -i, --enable-stdin ]
              Nu dezactiva stdin.

       [ -t, --category=<num> ]
              Configurați categoria pentru link-urile eD2k trecute la <num>

       [ -v, --version ]
              Afișează numărul versiunii curente.

       [ -h, --help ]
              Tipărește o scurtă descriere de utilizare.

       [ eD2k-link ]
              Adaugă o legătură eD2k la nucleu.

       Link-ul eD2k de adăugat poate fi:

          • un link fișier (ed2k://|file|...), va fi adăugat la coada descărcărilor,

          • o legătură server (ed2k://|server|...), care va fi adăugată la lista serverelor,

          • o legătură listă server, în care caz toate serverele din listă vor fi adăugate la lista serverelor;

          • o legătură magnet.

NOTE
   Căi
       Pentru toate opțiunile care iau o <path> valoare, dacă path nu conține nici o parte a unui director (ex. doar un nume de  fișier  simplu),  atunci  se
       consideră a fi sub directorul de configurare aMule, ~/.aMule.

FIȘIERE
       ~/.aMule/*
