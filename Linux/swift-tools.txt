NAME
       st-check-replication - a Swift-tools command

SYNOPSIS
       st-check-replication

DESCRIPTION
       st-check-replication check if Swift replication is in progress.

       Incidentally, check wether a swift cluster has dispersion, wich can occur after ring's modification for addition of disk for exemple
