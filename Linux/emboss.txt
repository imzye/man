NAME
       stretcher - Needleman-Wunsch rapid global alignment of two sequences

SYNOPSIS

       stretcher -asequence sequence -bsequence sequence [-datafile matrix] [-gapopen integer] [-gapextend integer] -outfile align

       stretcher -help

DESCRIPTION
       stretcher is a command line program from EMBOSS (“the European Molecular Biology Open Software Suite”). It is part of the "Alignment:Global" command
       group(s).

OPTIONS
   Input section
       -asequence sequence

       -bsequence sequence

       -datafile matrix
           This is the scoring matrix file used when comparing sequences. By default it is the file 'EBLOSUM62' (for proteins) or the file 'EDNAFULL' (for
           nucleic sequences). These files are found in the 'data' directory of the EMBOSS installation.

   Additional section
       -gapopen integer
           Default value: @($(acdprotein)? 12 : 16)

       -gapextend integer
           Default value: @($(acdprotein)? 2 : 4)

   Output section
       -outfile align
