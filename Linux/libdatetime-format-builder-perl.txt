NAME
       DateTime::Format::Builder::Parser::Strptime - strptime based date parsing

VERSION
       version 0.83

SYNOPSIS
           my $parser = DateTime::Format::Builder->create_parser(
               strptime => '%e/%b/%Y:%H:%M:%S %z',
           );

SPECIFICATION
       •   strptime

           strptime takes as its argument a strptime string. See DateTime::Format::Strptime for more information on valid patterns.
