NAME
     xfce4-terminal-theme-selector - simple curses-based theme selector for xfce4-terminal

SYNOPSIS
     xfce4-terminal-theme-selector

DESCRIPTION
     xfce4-terminal-theme-selector is a simple curses-based application that allows switching xfce4-terminal color themes from the command line.

     It provides an interactive interface for selecting and applying available terminal themes.
