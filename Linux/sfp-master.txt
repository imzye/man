NAME
       SFP-Master — SFP-module data programmer for CH341a devices

SYNOPSIS
       SFP-Master

DESCRIPTION
       SFP-Master  is a free GUI software programmer of optical SFP modules for CH341a devices. It can be used to read, write and save SFP module data to the
       computer. It requires an SFP to I2C adapter. This adapter is used to read and program SFP-module data.

       Connection: To work with the programmer, connect the SFP module to the connector in the SFP adapter, connect the SFP adapter to the CH341A  programmer
       device to the slot marked 24xx.  Connect the CH341A Programmer Unit to the USB connector of the computer and start the SFP-Master program.

       GitHub: https://github.com/bigbigmdm/SFP-Master

EXAMPLES
       You can run SFP-Master from a command line.
