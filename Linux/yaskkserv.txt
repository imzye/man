NAME
       update-skkdic-yaskkserv - create yaskkserv dictionaries on Debian

SYNOPSIS
       update-skkdic-yaskkserv

DESCRIPTION
       update-skkdic-yaskkserv is a program that creates yaskkserv format dictionary files from skkdic and/or skkdic-extra packages.

SEE ALSO
       yaskkserv_make_dictionary(1).
