NAME
       MooseX::Role::Logger - Provide logging via Log::Any (DEPRECATED)

VERSION
       version 0.005

DESCRIPTION
       MooseX::Role::Logger has been renamed to MooX::Role::Logger to clarify that it works with both Moo and Moose.  This role just wraps that one and is
       provided for backwards compatibility.

       See MooX::Role::Logger for usage details.
