Name
     ipscan - Fast and friendly IP address and port scanner

SYNOPSIS
     ipscan [OPTIONS]

DESCRIPTION
     Angry IP Scanner (ipscan) is a cross-platform network scanner designed to be fast and simple to use. It scans IP addresses in any range as well as any of their ports.

     By  default,  if launched without options, it starts the graphical user interface (GUI).  However, it also features a powerful command-line interface (CLI) mode for headless environments and automa‐
     tion.

     It works by pinging each IP address to check if it's alive, then optionally resolves its hostname, determines the MAC address, scans ports, etc. The amount of gathered data can be extended with plu‐
     gins.

OPTIONS
   General Options
     -h, --help
            Show a summary of command-line options and exit.

     -v, --version
            Display the application version.

   CLI Mode Options
     -s, --start
            Start the scanning process immediately using the provided configuration or defaults. Automatically runs in headless mode if combined with export arguments.

     -f:type <filename>
            Export scan results directly to a file. The type prefix determines the format:

            • txt  : Plain text file (e.g., -f:txt output.txt)

            • csv  : Comma-Separated Values (e.g., -f:csv output.csv)

            • xml  : XML document (e.g., -f:xml output.xml)

            • lst  : IP address list file

     -a <range>
            Specify the IP range to scan directly from the command line (e.g., 192.168.1.1-192.168.1.254).

     -p <ports>
            Specify the ports to scan (e.g., 80,443,8080 or 22-1024).

EXAMPLES
     Launch the Graphical Interface:
            ipscan

     Scan a local network subnet and save results to a CSV file without launching the GUI:
            ipscan -s -a 192.168.1.0-192.168.1.255 -f:csv report.csv

     Scan specific web server ports across a small range:
            ipscan -s -a 10.0.0.1-10.0.0.10 -p 80,443

SEE ALSO
     More detailed documentation is available online at <https://angryip.org/documentation/>
