NAME
     PstoeditQtGui - graphical frontend for pstoedit

SYNOPSIS
     PstoeditQtGui

DESCRIPTION
     PstoeditQtGui is a Qt-based graphical user interface for pstoedit(1), a tool for converting PostScript and PDF files to other vector graphics formats.
