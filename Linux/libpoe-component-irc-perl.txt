NAME
       POE::Component::IRC::Cookbook::Reload - Reload your bot's code after a change

SYNOPSIS
       Wouldn't it be neat if you could update your bot's code, and have the changes be applied without dropping the connection to the IRC server?

DESCRIPTION
       At first, this might seem complicated. You might have to mess with "eval STRING"/"do FILE", deal with scoping issues and what not. But when you really
       think about it, all you need is an IRC proxy. Let the proxy handle the IRC connection, and let the bot run as a separate process which you can restart
       at will.

       POE::Component::IRC itself can act as a proxy. See the Proxy plugin for details.
