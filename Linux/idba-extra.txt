NAME
       sim_reads_tran - Simulate sequencing reads from transcripts references and expression level profile.

SYNOPSIS
       sim_reads_tran ref.fa reads.fa

DESCRIPTION
       sim_reads_tran - Simulate sequencing reads from transcripts references and expression level profile.

   Allowed Options:
       --error_rate arg (=0.01)
              error rate

       --read_length arg (=100)
              read length

       --paired
              if paired-end

       --sd arg (=-1)
              sd

       --insert_distance arg (=500)
              insert distance
