NAME
       dnaplotter - make circular plots of genomes

SYNOPSIS
       dnaplotter [options]

OPTIONS
               -t FILE         Read a template file

EXAMPLES
               % dnaplotter
               % dnaplotter -t <template-file>

SEE ALSO
               https://sanger-pathogens.github.io/Artemis/DNAPlotter/
