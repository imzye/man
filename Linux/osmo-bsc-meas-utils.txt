NAME
       meas_json - utility to manage measurement reports (osmo-bsc)

SYNOPSIS
       meas_json

DESCRIPTION
       It  converts  measurement report feed into JSON feed printed to stdout. Each measurement report is printed as a separate JSON root entry. All measure‐
       ment reports are separated by a new line.

SEE ALSO
       osmo-bsc(1)
