NAME
     freecloud - synchronize files with a self-hosted FreeCloud drive

SYNOPSIS
     freecloud

DESCRIPTION
     FreeCloud is a desktop file browser and synchronization client for a FreeCloud installation hosted in a PHP-enabled web account.

     On first launch, enter the full website address of the hosted installation, choose a local synchronization folder, and optionally enter a password.

FILES
     ~/.config/freecloud/last_config.json
            Last-used desktop configuration.

     ~/.local/state/freecloud/
            Logs, process state, and the cached remote file tree.

     LOCAL_FOLDER/.freecloud_client.json
            Configuration for a synchronized local folder.

     LOCAL_FOLDER/.freecloud_state.json
            Synchronization state for a local folder.

SECURITY
     The desktop client currently stores the configured password in a local JSON configuration file. Review the security notes in the installed README before using FreeCloud with sensitive data.
