NAME
       ytnefprocess - process TNEF MIME parts in standard input

SYNOPSIS
       ytnefprocess < mailfile

DESCRIPTION
       This manual page documents briefly the ytnefprocess program.

       This manual page was written for the Debian™ distribution because the original program does not have a manual page.

       ytnefprocess is a command line utility which allows processing of TNEF attachments (also known as winmail.dat attachments) contained in MIME parts
       read from standard input.

       This can be useful to process messages from a mail reader which has no native TNEF support, but is able to pipe messages to other tools.

       The TNEF attachments found are replaced by the attached files existing in the winmail.dat cointainer.

FILES
       ~/.ytnef/pid
               Temporary directory for processing MIME parts of stdin.
