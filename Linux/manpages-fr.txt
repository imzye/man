NOM
       full - Périphérique toujours plein

CONFIGURATION
       Si votre système ne dispose pas encore du fichier /dev/full, vous pouvez le créer avec les commandes suivantes :

           mknod -m 666 /dev/full c 1 7
           chown root:root /dev/full

DESCRIPTION
       Les numéros de périphérique majeur et mineur du fichier /dev/full sont 1 et 7 respectivement.

       Les écritures vers le périphérique /dev/full échouent avec l'erreur ENOSPC. Cela peut être utilisé pour tester le comportement d'un programme face aux
       erreurs de disque plein.

       Les lectures depuis le périphérique /dev/full renvoient toujours des caractères \0.

       Les lectures (avec positionnements) sur /dev/full réussissent toujours.

FICHIERS
       /dev/full

VOIR AUSSI
       mknod(1), null(4), zero(4)
