NAME
     omnibor - Omnibor

DESCRIPTION
            omnibor (v0.0.1) - Generate OmniBOR ADG from files

            **USAGE** omnibor artifact-tree [files] omnibor bom [artifact-file] [artifact-tree-files [artifact-tree files...]]

            omnibor will create a .bom/ directory in the current working directory and store generated OmniBOR ADGs in .bom/
