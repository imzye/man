NAME
       pskc_set_key_algparm_resp_length - API function

SYNOPSIS
       #include <pskc.h>

       void pskc_set_key_algparm_resp_length(pskc_key_t * key, uint32_t length);

ARGUMENTS
       pskc_key_t * key
                   a pskc_key_t handle, from pskc_get_keypackage().

       uint32_t length
                   length of response to set.

DESCRIPTION
       Set  the  PSKC KeyPackage Key AlgorithmParameters ResponseFormat Length value.  This attribute defines the length of the response generated by the de‐
       vice and MUST be included.  If the 'Encoding' attribute is set to 'DECIMAL', 'HEXADECIMAL', or ALPHANUMERIC, this value indicates the number  of  dig‐
       its/characters.  If the 'Encoding' attribute is set to 'BASE64' or 'BINARY', this value indicates the number of bytes of the unencoded value.

SINCE
       2.2.0
