NAME
       Syntax::Highlight::Engine::Kate::Kate_File_Template - a Plugin for Kate File Template syntax highlighting

SYNOPSIS
        require Syntax::Highlight::Engine::Kate::Kate_File_Template;
        my $sh = new Syntax::Highlight::Engine::Kate::Kate_File_Template([
        ]);

DESCRIPTION
       Syntax::Highlight::Engine::Kate::Kate_File_Template is a  plugin module that provides syntax highlighting for Kate File Template to the
       Syntax::Haghlight::Engine::Kate highlighting engine.

       This code is generated from the syntax definition files used by the Kate project.  It works quite fine, but can use refinement and optimization.

       It inherits Syntax::Higlight::Engine::Kate::Template. See also there.
