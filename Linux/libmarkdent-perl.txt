NAME
       Markdent::Dialect::GitHub::SpanParser - Span parser for GitHub Markdown

VERSION
       version 0.40

DESCRIPTION
       This role adds parsing for some of the Markdown extensions used on GitHub. See http://github.github.com/github-flavored-markdown/ for details.

ROLES
       This role does the Markdent::Role::Dialect::SpanParser role.
