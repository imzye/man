NAME
       mido-connect - MIDI messages forwarder

SYNOPSIS
       mido-connect  remote-connectr-addres:port 'device-name-sending-messages'

DESCRIPTION
       This manual page documents briefly the mido-connect command.

       Forwards all messages that arrive on one or more ports to a server.
