NAME
     megacmd - Command-line interface for MEGA.nz cloud storage

SYNOPSIS
     megacmd [command] [options]

DESCRIPTION
     MEGAcmd is a command-line interface for interacting with the MEGA.nz cloud storage service.

     It provides a wide variety of commands for file management, synchronization, user control,
      debugging, and more.

COMMAND CATEGORIES
   1. Account / Contacts:
     These commands allow you to manage files and folders on your MEGA account:

     mega-signup Create a new MEGA account.      mega-confirm Confirm newly created account.        mega-invite Invite users to folders.

     mega-showpcr Show pending contact requests. mega-ipc Manages contact incoming invitations.   mega-users Shows your current list of contacts.

     mega-userattr Manage user attributes.       mega-passwd Change account password.

   2. Login / Logout:
     Authentication and user session commands:

     mega-login Authenticate and log in.         mega-logout Log out and end session.               mega-whoami Show current user info.

     mega-session Manage active sessions.        mega-killsession Kill remote session.

   3. Browse:
     mega-cd Change remote directory.            mega-lcd Set the local directory for downloads           mega-ls List directory contents.

     mega-pwd Show current remote directory.     mega-lpwd View the directory where downloads are saved.  mega-attr Manage file attributes.

     mega-du Show disk usage.                    mega-find Search for files.                              mega-mount Mount MEGA storage using FUSE

   4. Moving / Copying files:
     mega-mkdir Create new remote directories.    mega-cp Copy files.                         mega-put Upload files to MEGA.

     mega-get Download files from MEGA.           mega-preview Preview file contents.         mega-thumbnail Generate thumbnails.

     mega-mv Move or rename files.                mega-rm Remove files.                       mega-transfers Manage transfer queue.

     mega-speedlimit Configure speed limits.      mega-sync Manage sync folders.              mega-sync-issues List synchronization issues.

     mega-sync-ignore Ignore files during sync.   mega-sync-config Configure synchronization. mega-exclude Exclude files from syncing.

     mega-backup Create backups.

   5. Sharing:
     mega-export Export public links.             mega-import Import files or links.          mega-share Share files with other users.

     mega-webdav Run WebDAV server for MEGA.

   6. FUSE:
     mega-fuse-add Add new FUSE mount point.           mega-fuse-remove Remove FUSE mount.          mega-fuse-enable Enable FUSE support.

     mega-fuse-disable Disable FUSE support.           mega-fuse-config Configure FUSE behavior.    mega-fuse-show Show all FUSE mounts.

   7. Miscellaneous / Utility Commands:
     mega-cancel Cancel ongoing transfers or commands.        mega-cat Display file contents.               mega-cmd Main command-line interface.

     mega-confirmcancel Cancel account confirmation request.  mega-cmd-server Run background server daemon. mega-debug Debugging tools.

     mega-deleteversions Delete old file versions.            mega-df Show free/used disk space.            mega-errorcode Explain MEGA error codes.

     mega-exec Execute external commands.                     mega-ftp Run FTP server for MEGA.             mega-graphics Image processing operations.

     mega-help Display help for MEGAcmd commands.             mega-https Configure HTTPS settings.          mega-mediainfo Show media metadata.

     mega-log Show system logs.                               mega-permissions Manage file permissions.     mega-proxy Set proxy configuration.

     mega-quit Exit the MEGAcmd interface.                    mega-reload Reload sync configuration.        mega-tree Show directory tree.

     mega-version Show MEGAcmd version.
