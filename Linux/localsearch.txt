NAME
       localsearch-index - List and change indexed folders

SYNOPSIS
       localsearch index
       localsearch index --add [--recursive] <dir> [[dir] ...]
       localsearch index --remove <path> [[dir] ...]

DESCRIPTION
       This command causes the LocalSearch indexer to process the given directories. These changes are persistent across future restarts.

       If invoked without arguments, the currently indexed locations will be listed.

SEE ALSO
       localsearch-3(1).
