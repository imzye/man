NAME
       Log::Dispatch::FileRotate::Mutex - Flock Based File Mutex.

VERSION
       version 1.38

SYNOPSIS
       Internal Use Only!

DESCRIPTION
       Internal Use Only!

METHODS
   new($path)
       Create a new mutex for the given file path.  Only one mutex per path should be created.  The path will not actually be opened or locked until you call
       lock.

   lock()
       Obtains a lock on the path.  If the thread id or pid has changed since the path was opened, the path will be re-opened automatically in this thread or
       process.

   unlock()
       Releases the lock if the current thread or process is holding it.

   pid(): string
       Get the current process or thread id
