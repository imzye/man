NOME
       kalzium - Uma ferramenta de ensino de química baseada no KDE

SINOPSE

       kalzium [Opções] [--molecule nome-ficheiro]

DESCRIÇÃO
       O Kalzium é um programa que lhe mostra a Tabela Periódica dos Elementos (PSE - Periodic System of Elements). Poderá usar o Kalzium para procurar por
       determinadas informações sobre os elementos ou para aprender factos sobre a PSE.

       O Kalzium oferece-lhe todos os tipos de informação sobre a PSE. Poderá obter bastantes dados sobre os elementos e também as visualizações para os
       mostrar.

       Este pacote faz parte do módulo oficial de educação e entretenimento do KDE.

OPÇÕES
       --molecule nome-ficheiro
           Abre o ficheiro de moléculas indicado num dos formatos: cml, xyz, ent, pdb, alc, chm, cdx, cdxml, c3d1, c3d2, gpr, mdl, mol, sdf, sd, crk3d, cht,
           dmol, bgf, gam, inp, gamin, gamout, tmol, fract, mpd ou mol2.
