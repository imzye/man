NOME
       sensible-editor - lança editor de texto escolhido sensatamente

SINOPSE
       sensible-editor [OPTIONS...]

DESCRIÇÃO
       sensible-editor faz decisões sensatas sobre qual editor chamar. Os programas em Debian podem invocar este script para obter um bom editor predefinido.

       sensible-editor  looks  for  an  appropriate  choice  of editor in a series of places, and uses the first candidate that works.  It starts by checking
       environment variables, followed by a variable defined via select-editor, then tries the default editor command defined  by  the  alternatives  system,
       with a series of hard-coded command names as fallbacks.

       As  variáveis  pode ser saltadas se não definidas ou nulas, mas podem incluir parâmetros extra separados por espaços tais como uma bandeira --verbose.
       Assim que o sensible-editor tiver uma linha de comandos candidata, tentará corre-la (passando os argumentos que lhe foram dados como  os  ficheiros  a
       serem  editados).   Se isto falhar porque o comando não pôde ser executado (código de saída 126)  ou não foi encontrado (código de saída 127), tenta o
       próximo candidato.

       Os candidatos específicos que o sensible-editor tenta, por ordem são:

       • $VISUAL – veja environ(7)

       • $EDITOR – veja environ(7)

       • $SENSIBLE_EDITOR

       • $SELECTED_EDITOR – veja select-editor(1)

       • editor – veja editor(1), update-alternatives(1)

       • nano(1)

       • nano-tiny(1)

       • vi(1)

       Se tudo isto falhar, o sensible-editor termina com erro. Este sistema está  desenhado  para  facilitar  aos  utilizadores  individuais  definirem  uma
       predefinição personalizada e/ou temporária, sobrepondo as predefinições gerais do sistema.

VEJA TAMBÉM
       sensible-browser(1), sensible-pager(1), select-editor(1), environ(7), editor(1), update-alternatives(1)

DE ACORDO COM
       O  comportamento  do sensible-utils sob um sistema debian está documentado na secção 11.4 da debian-policy, disponível em /usr/share/doc/debian-policy
       se o debian-policy estiver instalado, ou online em https://www.debian.org/doc/debian-policy/
