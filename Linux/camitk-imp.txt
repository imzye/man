NAME
       camitk-imp - GUI flagship application for CamiTK

SYNOPSIS
       camitk-imp [OPTIONS]... [FILES]...

DESCRIPTION
       camitk-imp is build using CamiTK 6.0
       Please visit <https://camitk.imag.fr> for more information.
       (c) Univ. Grenoble Alpes, CNRS, Grenoble INP - UGA, TIMC, France

       camitk-imp  is a medical image analysis and modeling software.  This is the flagship GUI application of a larger framework called CamiTK (Computer As‐
       sisted Medical Interventions Tool Kit) designed to ease the collaborative work of a research team.

       The targeted users are in R&D departments or laboratories.  camitk-imp provides an easy and interactive access to all your data and algorithm  parame‐
       ters.

       camitk-imp can visualize medical images from a lot of different (standard) formats, offers image processing and segmentation algorithms to reconstruct
       a mesh geometry and run a biomechanical simulation.

OPTIONS
       --help|-h
              Print usage information and exit.

       --version|-v
              Print CamiTK version message and exit

       --no-console|-n
              Disable CamiTK application console and redirect everything to the standard output (default=off)
