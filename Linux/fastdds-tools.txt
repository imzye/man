NAME
       fastdds - FastDDS tool

SYNOPSIS
       fastdds discovery [options]

       fastdds shm clean

DESCRIPTION
       fastdds discovery is an alias for the fast-discovery-server, which has its own manual page.

       fastdds  shm  is for shared memory management. Currently, only the clean action is implemented; it removes stale files which might remain after a pro‐
       gram using FastDDS with SHM transport has crashed.

SEE ALSO
       fast-discovery-server(1)
