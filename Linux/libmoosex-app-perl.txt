NAME
       MooseX::App::ParsedArgv::Value - Parsed value from @ARGV

DESCRIPTION
       Every instance of this class represents a value from @ARGV

METHODS
   key
       Parameter value or option key

   value
       Scalar value

   raw
       Raw value as supplied by the user
