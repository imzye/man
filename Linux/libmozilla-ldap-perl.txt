NAME
         Mozilla::LDAP::Utils.pm - Collection of useful little utilities.

SYNOPSIS
         use Mozilla::LDAP::Utils;

ABSTRACT
DESCRIPTION
OBJECT CLASS METHODS
       normalizeDN  This  function  will remove all extraneous white spaces in the DN, and also change all upper case characters to lower case. The only argument is
                    the DN string to normalize, and the return value is the new, clean DN.

EXAMPLES
       There are plenty of examples to look at, in the examples directory. We are adding more examples every day (almost).
