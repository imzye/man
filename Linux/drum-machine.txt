NAME
     drum-machine - create and play drum beats with a modern GTK4 interface

SYNOPSIS
     drum-machine

DESCRIPTION
     Drum  Machine  is an intuitive application for creating, playing, and managing drum patterns. It provides an infinite, grid-based pattern editor, custom samples with MIDI mapping, and export to both
     audio (WAV, FLAC, Ogg Vorbis, MP3) and MIDI files. The program is built with Python, GTK4 and libadwaita, integrating well with the GNOME desktop.

     Main features include:

            • Unlimited pattern pages with a carousel interface

            • Adjustable BPM and master volume

            • Custom drum sounds with per-sample MIDI note mapping

            • Save and load patterns

            • Audio export with metadata (artist, title, cover art) and repeat count

            • MIDI file export with proper note mapping

            • Keyboard shortcuts for all functions

USAGE
     Once the application is running:

            1.     Use the grid to create or edit patterns: each column is a step, each row a drum sound.

            2.     Add new sounds via the sample manager and map them to MIDI notes.

            3.     Navigate pattern pages using the carousel arrows.

            4.     Adjust BPM with the spin button or tap tempo.

            5.     Export your pattern from the menu: Audio Export or MIDI Export.

     Full keyboard shortcuts are available inside the application's menu (usually Ctrl+? or under "Keyboard Shortcuts" in the hamburger menu).
