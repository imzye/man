NAME
       Pithub::Repos::Actions::Workflows - Github v3 Repo Actions Workflows API

VERSION
       version 0.01043

DESCRIPTION
       This class is incomplete. It's currently missing support for "dispatches", "enable" and "timing". Please send patches for any additional functionality
       you may require.

METHODS
   get
       •   Get a single workflow.

               GET /repos/:owner/:repo/actions/workflows/:id

           Examples:

               my $a      = Pithub::Repos::Actions::Workflows->new;
               my $result = $a->get(
                   repo        => 'graylog2-server',
                   user        => 'Graylog2',
                   workflow_id => 81148,
               );

   list
       •   List workflows for a repo.

               GET /repos/:owner/:repo/actions/workflows

           Examples:

               my $a = Pithub::Repos::Actions::Workflows->new;
               my $result = $a->list(
                   repo       => 'graylog2-server',
                   user       => 'Graylog2',
               );
