NAME
       jtag - bsdl2jtag

SYNOPSIS
       bsdl2jtag

DESCRIPTION
       bsdl2jtag converts bsdl files to jtag files which can be used by B jtag. .B bsdl2jtag reads from stdin and produces its output on stdout.

OPTIONS
       none

FILES
       none
