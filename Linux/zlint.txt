NAME
       zlint-gtld-update - fetch information on generic top level domains

SYNOPSIS
       zlint-gtld-update [flags]

DESCRIPTION
       zlint-gtld-update  fetches  an  up-to-date  list of generic top level domains including delegation date and (if applicable) removal date and prints it
       stdout in JSON format.

       Options:

       -version

              Print ZLint version and exit

       Report bugs to https://github.com/zmap/zcertificate
