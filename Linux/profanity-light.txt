NAME
       /ping - the Profanity /ping command.

DESCRIPTION
       Sends an IQ ping stanza to the specified JID. If no JID is supplied, your chat server will be pinged.

SYNOPSIS
       /ping [<jid>]

ARGUMENTS
       <jid>
           The Jabber ID to send the ping request to.
