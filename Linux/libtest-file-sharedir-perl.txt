NAME
       Test::File::ShareDir::Dist - Simplified dist oriented ShareDir tester

VERSION
       version 1.001002

SYNOPSIS
           use Test::File::ShareDir::Dist {
               '-root' => 'some/root/path',
               'Dist-Zilla-Plugin-Foo' => 'share/DZPF',
           };

       "-root" is optional, and defaults to "cwd"

       NOTE: There's a bug prior to 5.18 with "use Foo { -key => }", so for backwards compatibility, make sure you either quote the key: "use Foo { '-key' =>
       }", or make it the non-first key.
