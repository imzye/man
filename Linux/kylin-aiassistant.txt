NAME
     kylin-aiassistant - AI assistant for the Kylin desktop

SYNOPSIS
     kylin-aiassistant [OPTIONS]

DESCRIPTION
     kylin-aiassistant  is  an  AI-powered  assistant  for the Kylin desktop environment.  It provides text conversation, voice input, document processing, and desktop integration features using local or
     cloud-based AI models.

OPTIONS
     -h, --help
            Display help on command-line options.

     --help-all
            Display help, including generic Qt options.

     -s, --silence
            Start silently in the background (e.g. for autostart).

     -l, --selected
            Start with the current text selection as input.

     -f, --file
            Start with a file to process.

FILES
     ~/.config/kylin-aiassistant/settings.ini
            Per-user configuration file.
