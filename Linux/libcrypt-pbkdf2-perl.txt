NAME
       Crypt::PBKDF2::Hash::DigestHMAC - Digest::HMAC hash support for Crypt::PBKDF2.

VERSION
       version 0.161520

DESCRIPTION
       Uses Digest::HMAC to make nearly any Digest-compatible module compatible with Crypt::PKBDF2 by driving it with the standard HMAC algorithm to combine
       the key and the data.

ATTRIBUTES
   digest_class
       The Digest class to use. Will be passed to "Digest->new".
