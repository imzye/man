NAME
       xdt-autogen - Run autotools on a Xfce source tarball

SYNOPSIS
       xdt-autogen

DESCRIPTION
       Runs autoconf, intltool, libtool, aclocal and others.

SEE ALSO
       Upstream documentation in /usr/share/doc/xfce4-dev-tools/README
