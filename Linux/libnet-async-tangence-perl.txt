NAME
       "Net::Async::Tangence::Protocol" - concrete implementation of "Tangence::Stream" for "IO::Async"

DESCRIPTION
       This subclass of IO::Async::Stream provides a concrete implementation of the Tangence::Stream mixin. It is not intended to be directly used by server
       implementations. Instead, it is subclassed as Net::Async::Tangence::Client and Net::Async::Tangence::ServerProtocol.
