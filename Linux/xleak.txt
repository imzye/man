NAME
     xleak —— terminal Excel viewer with interactive TUI

SYNOPSIS
     xleak [-i] [-H] [-s sheet] [-n rows] [-w cols] [--wrap] [--formulas] [--export format] [--list-tables] [-t table] [--config path] file

DESCRIPTION
     xleak is a command-line tool for viewing Excel spreadsheets directly in the terminal without requiring Microsoft Excel.  It supports .xlsx, .xls, .xlsm, .xlsb, and .ods files.

     When  invoked  without  -i, xleak prints a formatted table of the spreadsheet to standard output.  With -i, it launches a full interactive TUI with keyboard navigation, search, multi-sheet browsing,
     and clipboard support.

OPTIONS
   Viewing Options
     -s, --sheet sheet
             Sheet name or 1-based index to display.  Defaults to the first sheet.

     -n, --max-rows rows
             Maximum number of rows to display.  Set to 0 to show all rows.  Default: 50

     -w, --max-width cols
             Maximum column width in characters.  Default: 30

     --wrap  Wrap long text instead of truncating it.

     -f, --formulas
             Show raw formulas instead of computed values.

   Interactive Mode
     -i, --interactive
             Launch the interactive TUI mode.

     -H, --horizontal-scroll
             Enable horizontal scrolling with auto-sized columns in TUI mode

   Export Options
     -e, --export format
             Export the sheet to stdout in the specified format.  Possible values:
             csv   Comma-separated values
             json  JSON array of row objects
             text  Tab-separated plain text

   Table Options
     --list-tables
             List all named Excel tables in the workbook.  Output format: Sheet<tab>Table.  Only supported for .xlsx files.

     -t, --table table
             Extract and display a specific named Excel table.  Can be combined with --export.  Only supported for .xlsx files.

   General Options
     --config path
             Path to a custom configuration file.  Default: $XDG_CONFIG_HOME/xleak/config.toml.

     -h, --help
             Print help information.

     -V, --version
             Print version information.

INTERACTIVE CONTROLS
     The following keyboard shortcuts are available in TUI mode.

     Navigation:
     Up, k      Move cursor up one row
     Down, j    Move cursor down one row
     Left, h    Move cursor left one column
     Right, l   Move cursor right one column
     PageUp, Ctrl+u
                Scroll up one page
     PageDown, Ctrl+d
                Scroll down one page
     Home       Jump to start of current row
     End        Jump to end of current row
     Ctrl+Home, g
                Jump to first row
     Ctrl+End, G
                Jump to last row
     Tab        Switch to next sheet
     Shift+Tab  Switch to previous sheet

     Search:
     /          Enter search mode (type query, then Enter to confirm)
     n          Jump to next search match
     N          Jump to previous search match
     Esc        Clear active search
     Backspace  Delete last character in search query

     Actions:
     Enter      Show full cell content in a detail view
     c          Copy current cell value to clipboard
     C          Copy current row to clipboard
     t          Toggle colour theme
     Ctrl+g     Open cell jump dialog (enter a cell reference such as B5)
     ?          Show keyboard shortcut help overlay
     q          Quit

ENVIRONMENT
     XDG_CONFIG_HOME
             Base directory for user configuration files.  If unset, defaults to ~/.config

FILES
     $XDG_CONFIG_HOME/xleak/config.toml
             Configuration file for theme, UI options, and custom keybindings.  Created automatically on first run if absent.

EXAMPLES
     View the first sheet of a workbook:
           $ xleak report.xlsx

     View a specific sheet by name:
           $ xleak report.xlsx --sheet Q1 Results

     View a specific sheet by index:
           $ xleak report.xlsx --sheet 2

     Open in interactive TUI mode:
           $ xleak report.xlsx -i

     Show all rows without truncation:
           $ xleak report.xlsx -n 0

     Show raw formulas instead of values:
           $ xleak report.xlsx --formulas

     Export a sheet to CSV:
           $ xleak report.xlsx --export csv > output.csv

     Export a sheet to JSON:
           $ xleak report.xlsx --export json > output.json

     List all named tables in a workbook:
           $ xleak report.xlsx --list-tables

     Extract a named table as CSV:
           $ xleak report.xlsx --table SalesData --export csv

     Use a custom config file:
           $ xleak report.xlsx -i --config ~/my-xleak.toml
