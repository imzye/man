NAME
       Test::Unit::TkTestRunner - unit testing framework helper class

SYNOPSIS
           use Test::Unit::TkTestRunner;
           Test::Unit::TkTestRunner::main($my_testcase_class);

DESCRIPTION
       This class is the test runner for the GUI style use of the testing framework.

       It is used by simple command line tools like the TkTestRunner.pl script provided.

       The class needs as arguments the names of the classes encapsulating the tests to be run.
