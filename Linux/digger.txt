NAME
     digger-vala - Modern and feature-rich DNS lookup tool, a GUI for dig

SYNOPSIS
     digger-vala

DESCRIPTION
     Digger is a graphical DNS lookup tool built with GTK4 and libadwaita.  It provides a clean, intuitive interface for querying DNS records, testing DNS servers, and analyzing domain information.

     Key features include:

            • Advanced DNS Queries: Support for all major DNS record types (A, AAAA, MX, TXT, NS, CNAME, SOA, SRV, PTR, etc.) with DNSSEC validation.

            • DNS Blacklist Checking: Check IP addresses against multiple RBL providers in parallel.

            • Performance Monitor: Real-time DNS latency visualization for major providers.

            • WHOIS Integration: Domain registration lookup with intelligent caching.

            • Server Comparison: Compare response times and results across multiple DNS servers.

            • Batch Lookup: Query multiple domains at once from CSV/TXT files.

            • Export Manager: Save results to JSON, CSV, text, or Zone file formats.

            • History & Favorites: Keep track of your queries and save important domains.

            • Secure DNS: DNS-over-HTTPS (DoH) support for Cloudflare, Google, and Quad9.

            • Modern Interface: Built with GTK4 and Libadwaita for a native GNOME feel, including smart autocomplete and clipboard integration.
