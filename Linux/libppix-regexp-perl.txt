NAME
       PPIx::Regexp::Token::Quantifier - Represent an atomic quantifier.

SYNOPSIS
        use PPIx::Regexp::Dumper;
        PPIx::Regexp::Dumper->new( 'qr{\w+}smx' )
            ->print();

INHERITANCE
       "PPIx::Regexp::Token::Quantifier" is a PPIx::Regexp::Token.

       "PPIx::Regexp::Token::Quantifier" has no descendants.

DESCRIPTION
       This class represents an atomic quantifier; that is, one of the characters "*", "+", or "?".

       Note that if they occur inside a variable-length look-behind, '?' implies a minimum Perl version of 5.29.9, and '+' and '*' are regarded as parse
       errors and reblessed into the unknown token.

METHODS
       This class provides the following public methods. Methods not documented here are private, and unsupported in the sense that the author reserves the
       right to change or remove them without notice.

   could_be_quantifier
        PPIx::Regexp::Token::Quantifier->could_be_quantifier( '*' );

       This method returns true if the given string could be a quantifier; that is, if it is '*', '+', or '?'.
