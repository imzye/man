NAME
       awf-gtk4 — Theme preview application for GTK 4.

SYNOPSIS
       awf-gtk4 [-h] [-v] [-l] [-t theme] [-s filename] [--ltr] [--rtl]

DESCRIPTION
       A  widget  factory is a theme preview application for GTK. It displays the various widget types provided by GTK in a single window allowing to see the
       visual effect of the applied theme.

OPTIONS
       -h, --help
               Show help.

       -v, --version
               Show version number.

       -l      List available themes.

       -t theme, --theme theme
               Run with the specified theme.

       -s filename, --screenshot filename
               Run and save a png screenshot on SIGHUP.

       --ltr   Start with text from left to right (Left-To-Right).

       --rtl   Start with text from right to left (Right-To-Left).

ENVIRONMENT VARIABLES
       GTK_CSD=1                Enable CSD window.
       GTK_OVERLAY_SCROLLING=0  Set scrollbars always visible.

FILES
       /home/user/.awf-gtk-accels  Configuration of keyboard shortcuts.
