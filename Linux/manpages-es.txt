NOMBRE
       full - dispositivo siempre lleno

CONFIGURACIÓN
       Si su sistema no tiene creado aún el dispositivo. /dev/full, éste se puede crear con las siguientes órdenes:

           mknod -m 666 /dev/full c 1 7
           chown root:root /dev/full

DESCRIPCIÓN
       El fichero /dev/full tiene el valor 1 como número principal de dispositivo y el 7 como número secundario.

       Los  intentos  de  escritura  en  el  dispositivo /dev/full fallarán con un error ENOSPC. Esto puede emplearse para comprobar el comportamiento de una
       aplicación cuando se encuentra con el disco totalmente lleno.

       La lectura del dispositivo /dev/full siempre devuelve caracteres nulos (\0).

       Las búsquedas en /dev/full siempre tendrán éxito.

ARCHIVOS
       /dev/full

VÉASE TAMBIÉN
       mknod(1), null(4), zero(4)
