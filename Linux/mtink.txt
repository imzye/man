NAME
       mtinkc - programa para escolher quais impressoras EPSON controlar

SYNOPSIS

       mtinkc

DESCRIÇÃO
       Este manual documenta abreviadamente o comando mtinkc.

       Este manual foi escrito para a distribuição Debian GNU/Linux porque o programa original não tem um manual.

       O mtinkc pede-lhe para escolher a impressora EPSON que quer monitorizar.
