NAME
     URI::git - git URI scheme

SYNOPSIS
       use URI;

       my $uri = URI->new("git://github.com/miyagawa/remedie.git");
       $uri->host; # github.com
       $uri->path; # /miyagawa/remedie.git

DESCRIPTION
     URI::git is an URI scheme handler for <git://> protocol.
