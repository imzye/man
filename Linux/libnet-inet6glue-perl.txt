NAME
       Net::INET6Glue::FTP - adds IPv6 support to Net::FTP by hotpatching

SYNOPSIS
        use Net::INET6Glue::FTP;
        use Net::FTP;
        my $ftp = Net::FTP->new( '::1' );
        $ftp->login(...)

DESCRIPTION
       This module adds support for IPv6 by hotpatching support for EPRT and EPSV commands into Net::FTP and hotpatching pasv, port and _dataconn methods to
       make use of EPRT and EPSV on IPv6 connections.

       It also includes Net::INET6Glue::INET_is_INET6 to make the Net::FTP sockets IPv6 capable.
