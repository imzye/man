NAME
     SDR++ - SDR graphical frontend

SYNOPSIS
     sdrpp

DESCRIPTION
     Graphical application for using various SDR devices, including RTL-SDR, HackRF, Airspy and AirspyHF.

     It is written in C++ and using OpenGL backend.
