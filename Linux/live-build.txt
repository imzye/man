NAME
       lb build - Complete the bootstrap, chroot, binary, and source stages

SYNOPSIS
       lb build [live-build options]

DESCRIPTION
       lb build is a high-level command (porcelain) of live-build(7), the Debian Live tool suite.

       lb build calls all necessary live-build programs in the correct order to complete the bootstrap, chroot, binary, and source stages.

OPTIONS
       lb  build  has no specific options but understands all generic live-build options. See live-build(7) for a complete list of all generic live-build op‐
       tions.

FILES
       auto/build

SEE ALSO
       live-build(7)

       This program is a part of live-build.

HOMEPAGE

       <http://live.debian.net/manual/>.
