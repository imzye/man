Name
       dokuwiki-plugins-extra - Conglomeration package of DokuWiki plugins

Contents
       addnewpage:
       Put 'add new page' forms within pages, with optional namespace selection
       <https://github.com/dregad/dokuwiki-plugin-addnewpage>

       color:
       Opportunity to write colored text in DokuWiki
       <https://github.com/hanche/dokuwiki_color_plugin>

       dw2pdf:
       Export DokuWiki content to PDF
       <https://github.com/splitbrain/dokuwiki-plugin-dw2pdf>

       edittable:
       Provides a visual table editing and inserting interface
       <https://github.com/cosmocode/edittable>

       gitbacked:
       Sync/store DokuWiki pages and media in a git repository
       <https://github.com/woolfg/dokuwiki-plugin-gitbacked>

       indexmenu:
       Show a customizable and sortable index for a namespace
       <https://github.com/samuelet/indexmenu>

       mathjax:
       Enables MathJax parsing of TeX math expressions in wiki pages
       <https://github.com/liffiton/dokuwiki-plugin-mathjax>

       sortablejs:
       JavaScript for sortable tables
       <https://github.com/FyiurAmron/sortablejs>

       wrap:
       Universal plugin which combines the functionality of many other plugins
       <https://github.com/selfthinker/dokuwiki_plugin_wrap>
