NAME
       friskserver - network risk board-game server

SYNOPSIS
       friskserver &

DESCRIPTION
       friskserver is the server that controls a particular game of risk.  It will start up on the machine it is run on and wait for clients to connect.

NOTES
       The  server  (and client) normally use port 5324.  Changing this will require editing the source (RISK_PORT in riskgame.h) and then recompiling every‐
       thing to use that port.
