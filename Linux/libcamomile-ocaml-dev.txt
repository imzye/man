NAME
       camomilecharmap.pt - um tradutor de base de dados charmap para o camomile.

SYNOPSIS

       camomilecharmap [-d { directório }] [-help | --help] [ficheiro]

DESCRIÇÃO
       Este manual documenta brevemente o comando camomilecharmap.

       Este manual foi escrito para a distribuição Debian GNU/Linux porque o programa original não tem um manual.

       camomilecharmap foi feito para converter um ficheiro charmap standard num ficheiro .mar. Isto converte um ficheiro charmap standard para o formato de
       base de dados interno do camomile.

       -d directório
           Directório de saída.

       -help, --help
           Mostra mensagem de ajuda.

       ficheiro
           Ficheiro charmap.
