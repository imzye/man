NAME
       thumbor-doctor - diagnostic tool for Thumbor image service

SYNOPSIS
       thumbor-doctor

DESCRIPTION
       thumbor-doctor is a command-line utility that checks the Thumbor installation for configuration or runtime issues.

       It validates the environment, required dependencies, and key configuration settings to help troubleshoot issues related to Thumbor’s functionality.

       This script is intended to assist developers and system administrators in verifying that their Thumbor setup is functional and correctly installed.

OPTIONS
       This command currently accepts no options.

EXAMPLES
       Run a full diagnostic of your Thumbor installation:

              thumbor-doctor
