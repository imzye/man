NAME
       IO::All::LWP - Extends IO::All to HTTP URLs

SYNOPSIS
           use IO::All;

           $content < io('http://example.org');             # GET webpage into scalar
           io('http://example.org') > io('index.html');     # GET to file
           "hello\n" > io('http://example.org/index.html'); # PUT webpage

           # two ways of getting a page with a password:
           $content < io('http://me:secret@example.org');
           $content < io('http://example.org')->user('me')->password('secret');

DESCRIPTION
       This module extends IO::All for dealing with HTTP URLs.  Note that you don't need to use it explicitly, as it is autoloaded by IO::All whenever it
       sees something that looks like an HTTP URL.

       The SYNOPSIS shows some simple typical examples, but there are many other interesting combinations with other IO::All features! For example, you can
       get an HTTP URL and write the content to a socket, or to an FTP URL, of to a DBM file.

METHODS
       This is a subclass of IO::All::LWP. The only new method is "http", which can be used to create a blank IO::All::HTTP object; or it can also take an
       HTTP URL as a parameter. Note that in most cases it is simpler just to call io('http://example.com'), which calls the "http" method automatically.

OPERATOR OVERLOADING
       The same operators from IO::All may be used. < GETs an HTTP URL; > PUTs to an HTTP URL.
