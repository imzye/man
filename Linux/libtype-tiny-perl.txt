NAME
       Type::Coercion::FromMoose - a set of coercions borrowed from Moose

STATUS
       This module is considered part of Type-Tiny's internals. It is not covered by the Type-Tiny stability policy.

DESCRIPTION
       This package inherits from Type::Coercion; see that for most documentation.  The major differences are that "add_type_coercions" always throws an
       exception, and the "type_coercion_map" is automatically populated from Moose.

       This is mostly for internal purposes.
