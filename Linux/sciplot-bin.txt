NAME
     SciPlot - real-time SciPlot demonstration

DESCRIPTION
     sciplot-realtime reads whitespace- or comma-separated numeric data from standard input and updates the plot as each line arrives.

   Input format
     One sample per line; lines beginning with # are ignored.

     One column per line (y)
            The value is plotted on the Y axis; X auto-increments from 0.

     Two columns per line (x y)
            The first column is the X value, the second the Y value.

     N columns per line (x y1 y2 ...)
            The first column is X; each remaining column is a separate Y series.

            The number of series is fixed by the first data line; subsequent lines with fewer columns leave the remaining series unchanged for that sample.

            When standard input reaches EOF the plot window remains open for interactive use (axis toggles, PostScript export, etc.).

   Usage:
            sciplot-realtime [OPTION???]

     Read  whitespace-separated  numeric  data from standard input and plot each sample as it arrives.  One column: y (x auto-increments); two or more columns: x y1 [y2 ...].  Lines starting with '#' are
     ignored.

   Help Options:
     -h, --help
            Show help options

     --help-all
            Show all help options

     --help-gapplication
            Show GApplication options

   Application Options:
     -V, --version
            Show version information and exit

     -t, --title=TEXT
            Plot title (default: "Real-time Data")

     -x, --xlabel=TEXT
            X axis label

     -y, --ylabel=TEXT
            Y axis label

     -l, --legend=NAME,...
            Comma-separated series names

EXAMPLES
     Plot a single signal from a sensor:
            sensor-tool | sciplot-realtime --ylabel Temperature (C)

     Plot multiple signals with named series:
            multi-sensor | sciplot-realtime --legend ch1,ch2,ch3 --xlabel Sample

     Plot from a file (non-interactive preview):
            sciplot-realtime < data.txt

     Plot the output of ping round-trip times:
            ping host | awk '/time=/{gsub(/.*time=/,""); gsub(/ .*/,""); print}' | sciplot-realtime --ylabel RTT (ms) --xlabel Packet
