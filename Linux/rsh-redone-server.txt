
NAME
     rshd —— remote shell daemon

SYNOPSIS
     rshd

DESCRIPTION
     rshd is the server for the rsh(1) program.  The server provides a remote shell facility with authentication based on privileged port numbers from trusted hosts.

SEE ALSO
     rsh(1), rlogin(1), rlogind(8), rcp(1), rhosts(5), RFC 1282.
