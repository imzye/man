NAME
       Crypt::Random::Source::Weak - Abstract base class for weak random data sources

VERSION
       version 0.14

SYNOPSIS
           use Moo;
           extends qw(Crypt::Random::Source::Weak);

DESCRIPTION
       This is an abstract base class. There isn't much to describe.

METHODS
   is_strong
       Returns false
