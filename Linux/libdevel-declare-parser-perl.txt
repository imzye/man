NAME
       Devel::Declare::Parser::Codeblock - Parser for functions that just take a codeblock.

DESCRIPTION
       This parser can be used to define a function that takes ONLY a codeblock. This is just like a function with the (&) prototype. The difference here is
       that you do not need to end your block with a semicolon.

RESTRICTIONS
       Any arguments before the codeblock will be treated as a syntax error.
