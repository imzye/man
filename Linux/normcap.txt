NAME
     normcap - capture text and barcodes from screen selection

SYNOPSIS
     normcap

DESCRIPTION
     NormCap  is  an OCR-powered screen capture tool that extracts text, barcodes, and QR codes from any region you select on the screen.  The recognised content is automatically copied to the clipboard,
     without saving any image.

     It uses Tesseract for text recognition and an integrated decoder for barcodes and QR codes. Everything happens locally, no internet connection is needed, and no logs are kept.

     On GNOME, the system tray icon may not appear by default. Install the package gnome-shell-extension-appindicator to make it visible.

BUGS
