NAME
       AnyEvent::RipeRedis::Error - Class of error for AnyEvent::RipeRedis

DESCRIPTION
       Class of error for AnyEvent::RipeRedis. Objects of this class can be passed to callbacks.

CONSTRUCTOR
   new( $err_msg, $err_code )
       Creates error object.

METHODS
   message()
       Get error message.

   code()
       Get error code.
