NAME
       Catalyst::Restarter::Win32 - Uses Proc::Background to manage process restarts

DESCRIPTION
       This class uses Proc::Background, which in turn uses Win32::Process. The new process is run using the same command-line as the original script, but
       without any restart-based options.

       This is a big hack, but using forks just does not work on Windows.
