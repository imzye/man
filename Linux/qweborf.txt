NAME
       qweborf — Shares files using the HTTP protocol.

SYNOPSIS
       qweborf

DESCRIPTION
       Qweborf  provides  an easy to use interface to share local files using the HTTP protocol.  It can enable writing on the server, webdav and authentica‐
       tion.
