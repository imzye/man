NAME
     tsx - Node.js runtime enhanced with esbuild for loading TypeScript & ESM

SYNOPSIS
     tsx [flags...] [script path]
     tsx command

DESCRIPTION
     tsx is a Node.js runtime enhanced with esbuild that enables direct execution of TypeScript and ESM (ECMAScript Module) files without a separate compilation step.

COMMANDS
     watch  Run the script and watch for changes. Automatically restarts the process when the script or its dependencies are modified.

FLAGS
     -h, --help
            Show help information and exit.

     --no-cache
            Disable caching of compiled files.

     --tsconfig string
            Specify a custom tsconfig.json path to use instead of the default.

     -v, --version
            Show the current version and exit.

EXAMPLES
     Run a TypeScript file:

            tsx script.ts

     Run a file and watch for changes:

            tsx watch script.ts

     Run with a custom tsconfig:

            tsx --tsconfig ./tsconfig.prod.json script.ts
