NAME
       optex - OPmac and Plain TeX for LuaHBTeX engine.

SYNOPSIS
       optex [ first line ]

DESCRIPTION
       This manual page was derived from the manual page for LaTeX and is not meant to be exhaustive.  The complete documentation for this version of TeX can
       be found in the info file or manual Web2C: A TeX implementation.

       OpTeX  is LuaTeX macro package initialized as the LuaHBTeX format optex.fmt.  It is based on Plain TeX macros by Donald Knuth and on OPmac macros from
       csplain package. For more information about it see http://petr.olsak.net/optex web page.
