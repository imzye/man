NAME
       Module::Compile::Opt - Provide options to Module::Compile

SYNOPSIS
           > export PERL5OPT=-MModule::Compile::Opt=-ext,p,pm
           > perl -c lib/Foo.p
           > cat lib/Foo.pm

DESCRIPTION
       module::Compile::Opt allows you to give runtime options to Module::Compile By default Module::Compile compiles a module in a ".pm" file into a ".pmc"
       file.
