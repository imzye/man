NAME
       WWW::IndexParser::Entry - Object representing an item in a directory

SYNOPSIS
        my @files = WWW::IndexParser->new('http://www.james.rcpt.to/misc/');
        foreach my $file (@files) {
          print $file->url;
        }

DESCRIPTION
       WWW::IndexParser::Entry is not used directly, but is the class of items returned by WWW::IndexParser when it successfully parses an auto index from a
       web server.

METHODS
       filename
       url
       size
       size_units
       type

OSNAMES
       any
