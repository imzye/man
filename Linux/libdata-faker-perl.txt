NAME
       Data::Faker::Company - Data::Faker plugin

SYNOPSIS AND USAGE
       See Data::Faker

DATA PROVIDERS
       company
           Return a fake company name.

       company_suffix
           Return a company suffix (Inc, LLC, etc).

       job_title
           Return a job title
