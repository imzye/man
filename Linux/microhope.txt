NAME
       uhope - Interactive program to learn microcontroller programming.

SYNOPSIS

       uhope

DESCRIPTION
       uhope launches an Integrated Development Environment (IDE) which allows the user to develop several small programs for the ATmega32 microcontroller.
       This environment comes with useful examples and libraries which make the learn process easy.

       This program has features quite identical to microhope which is implemented in Python. However, uhope is implemented in C language with gtk2 graphic
       libraries.
