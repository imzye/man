NOME
       full - disposítivo sempre completo

CONFIGURAÇÃO
       Se seu sistema não possui criado /dev/full, ele pode ser criado com os seguintes comandos:

           mknod -m 666 /dev/full c 1 7
           chown root:root /dev/full

DESCRIÇÃO
       O arquivo /dev/full tem o número de dispositivo principal 1 e o número de dispositivo secundário 7.

       Writes to the /dev/full device fail with an ENOSPC error.  This can be used to test how a program handles disk-full errors.

       Reads from the /dev/full device will return \0 characters.

       Procura em /dev/full sempre terá sucesso.

ARQUIVOS
       /dev/full

VEJA TAMBÉM
