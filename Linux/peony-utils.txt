NAME
       meta-get - utils for get file meta info.

SYNOPSIS
       meta-get [OPTION] <path> [keys..]

DESCRIPTION
       meta-get This program provides several commands for get file meta info.

        -t, --tree
              Tree

        -f, --file
              Tree file

        -r, --recursive
              Recursive
