NAME
       MooseX::MultiInitArg::Attribute - A custom attribute metaclass to add multiple init arguments to your attributes.

DESCRIPTION
       This is a custom attribute metaclass which you can add to an attribute so that you can specify a list of aliases for your attribute to be recognized
       as constructor arguments.  Use MooseX::MultiInitArg::Trait for a way to use this with other attribute modifiers.
