NAME
       Email::MIME::Kit::Role::KitReader - things that can read kit contents

VERSION
       version 3.000008

PERL VERSION
       This library should run on perls released even a long time ago.  It should work on any version of perl released in the last five years.

       Although it may work on older versions of perl, no guarantee is made that the minimum required version will not be increased.  The version may be
       increased for any reason, and there is no promise that patches will be accepted to lower the minimum required perl.

IMPLEMENTING
       This role also performs Email::MIME::Kit::Role::Component.

       Classes implementing this role must provide a "get_kit_entry" method.  It will be called with one parameter, the name of a path to an entry in the
       kit.  It should return a reference to a scalar holding the contents (as octets) of the named entry.  If no entry is found, it should raise an
       exception.

       A method called "get_decoded_kit_entry" is provided.  It behaves like "get_kit_entry", but assumes that the entry for that name is stored in UTF-8 and
       will decode it to text before returning.
