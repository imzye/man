NAME
       adnsheloex - Asynchronous-capable DNS client utilities

DESCRIPTION
       usage: adnsheloex [<options>] [<logfile>]

              adnsheloex --version|--help

       options: -c <concurrency>  set max number of outstanding queries

       -p     use poll(2) instead of select(2)

       -d     turn on debugging

       -C <config>
              use instead of contents of resolv.conf
