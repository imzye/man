NAME
       Acme::DWIM - Perl's confusing operators made easy

SYNOPSIS
               use Acme::DWIM;

               my ($x) = +("Hullo " x 3 . "world" & "~" x 30) =~ /(.*)/;
               $x =~ tr/tnv/uow/;
               print $x;

DESCRIPTION
       The first time you run a program under "use Acme::DWIM", the module replaces all the unsightly operators et al. from your source file with the new
       DWIM operator: "..." (pronounced "yadda yadda yadda").

       The code continues to work exactly as it did before, but now it looks like this:

       use Acme::DWIM;

               my ($x) ... ...("Hullo " ... 3 ... "world" ... "~" ... 30) ... /(...)/;
               $x ... tr/tnv/uow/;
               print $x;

       ...head1 DIAGNOSTICS

       ...over 4

       ...item C...<Can't enDWIM '%s'>

       Acme::DWIM could not access the source file to modify it.

       "Can't DWIM '%s'"...
           Acme...DWIM could not access the source file to execute it...
