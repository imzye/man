NOMBRE
       apt-build - Obtiene las fuentes y construye paquetes optimizados para su arquitectura

SINOPSIS
       apt-build [ options ] [ update ] [ upgrade ] [ world ] [ install pkg ] [ remove pkg ] [ info pkg ]

DESCRIPCIÓN
       apt-build es un frontal de «apt-get» para construir e instalar paquetes optimizados para una determinada arquitectura.

ÓRDENES
       update Obtiene una nueva lista de paquetes

       upgrade
              Ejecuta una actualización

       world  Reconstruye todo su sistema

       install
              Construye e instala paquetes nuevos

       source Descarga y extrae paquetes fuente en el directorio de construcción

       info   Obtiene información de un paquete que se podría construir

       remove Elimina los paquetes

       clean-build
              Elimina los paquetes construidos

       clean-sources
              Invoca debian/rules en los directorios de fuentes

       build-source
              Construye el paquete sin instalarlo

       update-source
              Actualiza los paquetes fuente y los reconstruye si no están en el repositorio

       build-repository
              Reconstruye el repositorio

OPCIONES
       --help
              Muestra la ayuda

       --nowrapper
              No usar el «wrapper» (envoltorio) de gcc

       --remove-builddep
              Elimina las dependencias de compilación instaladas por apt-build

       --no-source
              No descargar las fuentes

       --build-dir
              Especifica build-dir (directorio de construcción)

       --build-only
              Sólo construye el paquete

       --rebuild
              Reconstruye un paquete

       --reinstall
              Construye e instala un paquete ya instalado

       --build-command <command>
              Use esta orden para construir el paquete

       --patch <file>
              Aplica este parche antes de construir (puede usar esta opción una o varias veces)

       --patch-strip, -p <number>
              Especifica el número de prefijos que omitirá patch (0 = -p0, 1 = -p1 ...)

       --yes, -y
              Responde afirmativamente a toda pregunta

       --purge
              Usa «purge» (purgar) en vez de «remove» (eliminar)

       --noupdate
              No ejecuta «apt-get update» antes de instalar los paquetes

       --sources-list
              Especifica un archivo «sources.list»

       --apt-get
              Especifica una orden de «apt-get» alternativa

       --apt-cache
              Especifica una orden de «apt-cache» alternativa

       --force-yes
              Fuerza «yes» ante preguntas

       --source
              No descargar la fuentes (las fuentes ya se han extraído)

       --repository-dir
              Especifica el directorio del repositorio

       --target-release
              Distribución de la que obtener los paquetes

       --config
              Especifica un archivo de configuración alternativo

       --version, -v
              Ver versión

FALLOS
       Muchos.
