NAME
     kylin-ai-vector-engine-default - default startup wrapper for Kylin AI Vector Engine

SYNOPSIS
     kylin-ai-vector-engine-default

DESCRIPTION
     kylin-ai-vector-engine-default is a wrapper script that initializes the runtime environment and starts kylin-ai-vector-engine(1) as a user service.

     On startup, the script:

     • Creates the user data directory if it does not exist.

     • Migrates the database from the legacy location (~/.local/share/milvus-lite/default.db) if present.

     • Initializes the database from the system template (/usr/lib/kylin-ai-vector-engine/default.db) on first run.

     • Acquires a file lock to prevent concurrent instances.

     • Starts the engine listening on a Unix domain socket.

ENVIRONMENT
     LOG_LEVEL
            Logging verbosity passed to the engine.  Defaults to ERROR.

     TMPDIR
            Base directory for the lock file and Unix socket.  Defaults to /tmp.

FILES
     ~/.local/share/kylin-ai-vector-engine/default.db
            Per-user database file (created on first run).

     /usr/lib/kylin-ai-vector-engine/default.db
            Read-only system database template.

     /tmp/kylin-ai-vector-engine-*.lock
            Lock file for preventing concurrent instances.

     /tmp/kylin-ai-vector-engine-*.sock
            Unix domain socket for gRPC communication.

EXIT STATUS
     0      Clean shutdown (signal received or lock released).

     1      Database initialization failure, invalid database name, or concurrent instance running.
