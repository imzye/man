NAME
       deskflow-core - Keyboard and mouse sharing utility

SYNOPSIS
       deskflow-core coremode [options]

DESCRIPTION
       deskflow-core: 1.26.0

       Keyboard and mouse sharing utility

OPTIONS
       -h, --help
              Display Help on the command line

       -v, --version
              Display version information

       --new-instance
              Skip the check for a running instance, always makes a new instance

       -s, --settings <configFile>
              override configuration file to use

   Arguments:
       coremode
              The mode to start in either: server or client
