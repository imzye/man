NAME
       FFI::Build::File::CXX - Class to track C source file in FFI::Build

VERSION
       version 2.11

SYNOPSIS
        use FFI::Build::File::CXX;

        my $c = FFI::Build::File::CXX->new('src/foo.cxx');

DESCRIPTION
       File class for C++ source files.
