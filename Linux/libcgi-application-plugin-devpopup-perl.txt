NAME
       CGI::Application::Plugin::DevPopup::Query - show CGI query in DevPopup window

SYNOPSIS
           use CGI::Application::Plugin::DevPopup;
           use CGI::Application::Plugin::DevPopup::Query;

           The rest of your application follows
           ...

DESCRIPTION
       This module is a plugin for CGI::Application::Plugin::DevPopup.  Whenever used, it creates two sections in the DevPopup output.  First section,
       "Current Run Mode", shows name of run mode executed.  Second section, "CGI Query", contains a list of CGI query parameters and associated values
       passed to your CGI::Application.

       See "query()" in CGI::Application and CGI.pm for more information about query parameters.
