NAME
       fixcr - make sure that there is a CR before each LF

SYNOPSIS
       fixcr

DESCRIPTION
       fixcr inserts CR at the end of each line of input where a CR is not already present.  It does not insert CR at the end of a partial final line.

SEE ALSO
       addcr(1)
