NAME
       Config::Model::models::LCDd::lb216 - Configuration class LCDd::lb216

DESCRIPTION
       Configuration classes used by Config::Model

       generated from LCDd.conf

Elements
   Brightness
       Set the initial brightness  Optional. Type integer.

       upstream_default value :
           255

   Device
       Select the output device to use  Optional. Type uniline.

       upstream_default value :
           /dev/lcd

   Reboot
       Reinitialize the LCD's BIOS  Optional. Type boolean.

       upstream_default value :
           no

   Speed
       Set the communication speed  Optional. Type enum. choice: '2400', '9600'.

       upstream_default value :
           9600
