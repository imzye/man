NAME
       Config::Model::models::Itself::CommonElement::Assert - Configuration class Itself::CommonElement::Assert

DESCRIPTION
       Configuration classes used by Config::Model

Elements
   code
       Perl instructions to test the value. $_ contains the value to test. $self contains the value object. Use with care.  Optional. Type string.

   msg
       Warning message to show user. "$_" contains the bad value. Example "value $_ is bad". Leave blank or undef to use generated message.  Optional. Type
       string.

   fix
       Perl instructions to fix the value. These instructions may be triggered by user. $_ contains the value to fix.  $_ is stored as the new value once the
       instructions are done. $self contains the value object. Use with care.  Optional. Type string.
