NAME
       xbtop - interactive monitor for XRT device metrics

SYNOPSIS
       xbtop -d BDF [-r SECONDS]

DESCRIPTION
       xbtop  displays live accelerator device metrics in a terminal interface, including memory usage, DMA transfer statistics, dynamic region activity, and
       power data.

       The interface is interactive and refreshes continuously until quit.

OPTIONS
       -d, --device
              Target device BDF (required).

       -r, --refresh_rate
              Refresh period in seconds.

       -h, --help
              Show help and exit.

INTERACTIVE KEYS
       q      Quit.

       n / p  Next / previous report.

       < / >  Previous / next page.
