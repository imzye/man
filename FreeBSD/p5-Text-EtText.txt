NAME
     ethtml2text - convert from HTML to the EtText editable-text format

SYNOPSIS
       ethtml2text file.html > file.txt

DESCRIPTION
     ethtml2text will convert a HTML file into the EtText editable-text
     format, for use with webmake or ettext2html.

     For more information on the EtText format, check the WebMake
     documentation on the web at http://ettext.taint.org/ .

INSTALLATION
     The ethtml2text command is part of the HTML::WebMake Perl module set.
     Install this as a normal Perl module, using "perl -MCPAN -e shell", or by
     installing WebMake.

ENVIRONMENT
     No environment variables, aside from those used by perl, are required to
     be set.
