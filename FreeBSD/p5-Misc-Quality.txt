NAME
     Astro::Quality - Class for handling quality flags for astronomical
     objects.

SYNOPSIS
       use Astro::Quality;

       $quality = new Astro::Quality( 'derived' => 1 );

       $derived = $quality->query('derived');

       $quality->set( 'derived' => 0 );

DESCRIPTION
     Class for handling quality flags for astronomical objects. This class can
     handle any type of flag used.
