NAME
     crucible-bootstrap - bootstrap test data

SYNOPSIS
     crucible bootstrap <test-name> [--width <image-width>] [--height <image-height>]

DESCRIPTION
     When running a test in bootstrap mode, image dumps are automatically
     enabled.
