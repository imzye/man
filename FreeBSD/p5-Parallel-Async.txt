NAME
     Parallel::Async - run parallel task with fork to simple.

SYNOPSIS
         use Parallel::Async;

         my $task = async {
             print "[$$] start!!\n";
             my $msg = "this is run result of pid:$$."; # MSG
             return $msg;
         };

         my $msg = $task->recv;
         say $msg; # same as MSG

DESCRIPTION
     Parallel::Async is yet another fork tool.  Run parallel task with fork to
     simple.

     See also Parallel::Async::Task for more usage.

SEE ALSO
     Parallel::ForkManager Parallel::Prefork
