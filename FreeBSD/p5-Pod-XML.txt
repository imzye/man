NAME
     pod2xml - convert POD to XML

SYNOPSIS
       pod2xml [--encoding foobar] [infile [outfile]]

DESCRIPTION
     Takes the file specified on the command line and converts its POD
     contents to XML.

SEE ALSO
     Pod::Parser, Pod::XML
