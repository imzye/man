NAME
     vns-gen

SYNOPSIS
       vns-gen --help

DESCRIPTION
     Generate Venus source code. This CLI dispatches to "perform" in
     Venus::Task::Venus::Gen.

EXAMPLES
       # generate a Venus class
       $ vns-gen --stdout --class

       # generate a Venus test
       $ vns-gen --stdout --test

SEE ALSO
     Venus, Venus::Task::Venus::Gen.
