NAME
     gff3_from_fasta - make GFF3 from fasta sequences

DESCRIPTION
     Thin wrapper for gff3_from_fasta function in
     Bio::GFF3::Transform::FromFasta.

USAGE
       gff3_from_fasta -t SO_type -s source_name  file1.fasta  file2.fasta ... > my.gff3
