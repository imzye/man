NAME
     gspiceui - A GUI front-end for various electronic circuit simulation
     engines


SYNOPSIS
     gspiceui [-OPTION] [ARG]] [FILE/S]


DESCRIPTION
     GNU SPICE GUI provides a GUI front-end for various freely available
     electronic circuit simulation engines ie. NG-SPICE and GNU-CAP. It's core
     function is to generate simulation engine instructions based on user
     input. However, it also offers extra functionality via applications and
     utilities developed by others. Electronic Design Automation (EDA) tool
     suites are used to provide schematic capture and editing, and schematic
     to netlist conversion. Waveform data viewers are used to display
     simulation results and PDF viewers to display user manuals.


OPTIONS
     gspiceui accepts the following options :


     -h          Print usage information and quit.


     -v          Print version information and quit.


     -c          Rebuild/clean the configuration file and quit.


     -d          Enable debug mode (generate console spew on stderr).


     -r <RCFILE> Specify a configuration file.


     -s <SIMENG> Specify the simulation engine to be used.


     -e <EDA>    Specify the EDA tool suite to be used.


     -w <WAVWR>  Specify the waveform data viewer to be used.


     -g [<PROC>] Import schematic file/s and (optionally) specify the Guile
                 procedure to use.


     -a <PAGE>   Specify the analysis page to be displayed.


     NOTE : Option -s should come before -a if both are specified.


FILE/S
     Specify a circuit description (netlist) file to load or schematic file/s
     to import. If multiple schematics files are specified they are read
     sequentially and parsed with the assumption that they are all part of the
     same design. All file/s must be specified at the end of the command line.
