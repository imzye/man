VCP::Filter::cvsbkchangeset(3)             User Contributed Perl Documentation

NAME
     VCP::Filter::cvsbkchangeset - alter cvsbk revisions for proper log
     message

SYNOPSIS
        vcp cvsbk:/home/cvs:/module...cvsbkchangeset:

DESCRIPTION
     The filter strips the ChangeSet control file from revisions generated by
     VCP::Source::cvsbk source driver after copying the comments to revisions
     that belong to the same chagneset.

     Additionally revisions with "change_id" 0 are dropped as cvsbk source
     driver gives that for initial revisions.

NOTES
     The filter should be inserted right before the VCP::Dest driver.
