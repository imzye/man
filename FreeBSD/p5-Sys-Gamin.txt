NAME
     monitor - monitor filesystem activity with FAM

SYNOPSIS
     monitor directory | file ...

DESCRIPTION
     Provides a running tally of FAM events affecting the specified files or
     directories. Blocks separated by dotted lines indicate contiguous chunks
     of events in the event queue. Should be self-explanatory.

     Hit interrupt to stop the monitoring.

SEE ALSO
     See SGI::FAM(3) for the workings.
