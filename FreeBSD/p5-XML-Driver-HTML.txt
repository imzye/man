NAME
     html2xhtml - dirty command line interface to XML::Driver::HTML

SYNOPSIS
       html2xhtml < filename.html > filename.xhtml

DESCRIPTION
     html2xhtml is a filter to convert html files to xhtml files.

OPTIONS
     no options yet ;-(

     I think that the set of options used in YAWriter are a good start, lets
     look what we additonal need for processing batches.
