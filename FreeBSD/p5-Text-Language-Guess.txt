NAME
         language-guess - Guess the language of a text file

SYNOPSIS
         language-guess file ...

OPTIONS
     -h      Prints this manual page in text format.

     -v      Prints the current version of language-guess.

DESCRIPTION
     language-guess takes one or more file names as arguments and guesses for
     each one which language it is written in. It uses Text::Language::Guess,
     please see its manual page for details.

EXAMPLES
       $ language-guess bill.txt
