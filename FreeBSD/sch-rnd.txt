NAME
     boxsym-rnd - generate box shaped symbol(s)

SYNPOSIS

     boxsym-rnd &lt; infile.bs &gt;

DESCRIPTION
     boxsym-rnd reads a boxsym description text file from the user specified
     path infile.bs and generates one or more sch-rnd symbols in the same
     directory as the infile is in, named infile.sym and infile-*.sym (for
     slotted boxsyms).boxsym-rnd(5)
