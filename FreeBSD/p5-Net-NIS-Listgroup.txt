NAME
     listgroup - Lists hosts/users in a netgroup group.

SYNOPSIS
         listgroup

         listgroup [--host] groupname1 [ [-]groupname2 [-]groupname3 ... ]

         listgroup [--user] groupname1 [ [-]groupname2 [-]groupname3 ... ]

DESCRIPTION
     Lists groups or members of a netgroup NIS map.  listgroup without any
     parameters lists all the available netgroup groups.

     With groupname parameters, listgroup will recusively list the members of
     the named groups.  Each member in a group is a triplet of
     (host,user,domain).  The host portion or user portion of the members is
     returned depending upon whether --host or --user is used.  If neither
     --host or --user is used, listgroup will return the host portion.

     If a {groupname} is preceded with a -, members of that group will be
     excluded from the output.

     Groups are processed in the order they appear on the command line.

OPTIONS
     --host
         Restrict output to only contain the host portion of the members in
         the groupname.

     --user
         Restrict output to only contain the user portion of the members in
         the groupname.

REQUIRES
     Perl Modules:

         Net::NIS::Listgroup
         Net::NIS

SEE ALSO
     netgroup(4), Net::NIS::Listgroup(3), Net::NIS(3)
