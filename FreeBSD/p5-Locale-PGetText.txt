NAME
     MsgFormat - messages database compiler for PGetText

SYNOPSIS
       MsgFormat <LocaleDir> <Language> < myprog.po

DESCRIPTION
     MsgFormat creates database in <LocaleDir> directory with messages from
     <myprog.po> for language <Language>

SEE ALSO
     Locale::PGetText
