NAME
     idea – launch IntelliJ IDEA Java Integrated Development Environment

SYNOPSIS
     idea [jvm-args]

DESCRIPTION
     idea starts up the IntelliJ IDEA Community Edition Java Integrated
     Development Environment.

SEE ALSO
     The web site http://www.jetbrains.com/idea/.
