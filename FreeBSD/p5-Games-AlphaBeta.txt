NAME
     othello-demo - a self-playing Othello game

SYNOPSIS
       othello-demo

DESCRIPTION
     This is an example of how simple a self-playing Othello (aka Reversi)
     program can be created using Games::AlphaBeta and
     Games::AlphaBeta::Reversi.
