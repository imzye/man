NAME
     wallust-cs - Apply a certain colorscheme

SYNOPSIS
     wallust-cs [-f|--format] [-h|--help] <COLORSCHEME>

OPTIONS
     -f, --format <FORMAT>
            Specify a custom format. Without this option, wallust will
            sequentially try to decode it by trying one by one

            Possible values:

                   • pywal: uses the wal colorscheme format, see
                     <https://github.com/dylanaraps/pywal/tree/master/pywal/colorschemes>

                   • terminal-sexy: uses <https://terminal.sexy> JSON export

                   • wallust: cached wallust files

     -h, --help
            Print help (see a summary with '-h')

     <COLORSCHEME>
            Name of the scheme inside `wallust/colorschemes` directory or the
            name of a theme
