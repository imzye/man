NAME
     poudriere audit – Audit packages.

SYNOPSIS
     poudriere audit [options]

DESCRIPTION
     This command will audit the package repository using pkg-audit(8).  It
     requires a host pkg(8) be installed.

OPTIONS
     -j name      Specifies the name of the jail to use for the package
                  repository.

     -p tree      Specifies which ports tree to use for the package
                  repository.

     -z set       Specifies which set to use for the package repository.
