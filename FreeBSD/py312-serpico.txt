NAME
     serpico – Security scanner for FreeBSD packages and releases

SYNOPSIS
     serpico [--scan-jails] [--no-fetch-audit-db] [--category CATEGORY]
             [--security-feed SECURITY_FEED] [--nvd-api-key NVD_API_KEY]
             [--nvd-api-key-file NVD_API_KEY_FILE]
             [--nvd-request-delay NVD_REQUEST_DELAY] [--cve-lang CVE_LANG]

DESCRIPTION
     serpico is a security scanner for FreeBSD packages and releases that
     compares the versions against a list of versions marked as vulnerable,
     then displays vulnerability information in a JSON-compact format for easy
     analysis by other security tools.

     --scan-jails
          serpico only scans the host. With this option, jails with a meta set
          to "meta.serpico=1" are taken into account for analysis. Please note
          that only ALPHA, BETA, RC, and RELEASE can be analyzed in this way;
          the others are ignored and a warning is displayed.

     --no-fetch-audit-db
          By default, serpico will fetch and update the audit database before
          performing an analysis.  This option disables this behavior, but
          keep in mind that if you have not retrieved the database, this will
          cause an error.

     --category CATEGORY
          Comma-separated list of scan types.

          There are three categories implemented in serpico:

           1.   package: Check if there are any vulnerable packages currently
                installed.
           2.   release: Check if the current version of this system is
                vulnerable.
           3.   all: Perform all of the analyses mentioned above. This is the
                default option.

     --security-feed SECURITY_FEED
          Location of the FreeBSD security feed for retrieving security
          advisories.  The default is
          https://www.freebsd.org/security/feed.xml

     --nvd-api-key NVD_API_KEY
          NVD API key for making requests.

          You can make HTTP requests without an API key, but this has some
          limitations and is slower.

     --nvd-api-key-file NVD_API_KEY_FILE
          Same as --nvd-api-key, but reads the first line of the specified
          file instead of passing the API key through the command line. Only
          one parameter can be specified, and this takes precedence.

     --nvd-request-delay NVD_REQUEST_DELAY
          Delay between requests.

     --cve-lang CVE_LANG
          Preferred language for displaying CVE information is available. If
          the specified language is not found, fallback to en (english).
