NAME
     Flowd::Serialiser - Perl extension for blah blah blah

SYNOPSIS
       use Flowd::Serialiser;

DESCRIPTION
     This module isn't really intended for public consumption. It is just a
     thin wrapper over the flowd C library. If you are really curious, have a
     look at Flowd.pm to see how it uses it (it is very simple).

   EXPORT
     None by default.

SEE ALSO
     Refer to Flowd.pm for usage information.
