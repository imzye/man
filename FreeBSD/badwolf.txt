NAME
     badwolf – minimalistischer und privatsphäre-orientierter Webbrowser
     basierend auf WebKitGTK

ÜBERSICHT
     badwolf [WebKit-/GTK-Optionen] [URLs oder Pfade]

BESCHREIBUNG
     badwolf ist ein minimalistischer Webbrowser, der die Privatssphäre seiner
     Nutzer respektiert. Er basiert auf WebKitGTK und akzeptiert daher alle
     Optionen und Umgebungsvariablen, die WebKitGTK (und Abhängigkeiten) auch
     akzeptieren, leider gibt es dafür keine Manpages.

     Laufzeitspezifische Konfigurationsmöglichkeiten für badwolf werden
     wahrscheinlich in einer späteren Version hinzugefügt.

TASTENKOMBINATIONEN
     Der folgende Abschnitt listet die unterstützten Tastenkombinationen und
     ihre Funktionen auf. Vor jeder Tastenkombination steht der greifende
     Kontext.

     webview Ctrl-Scroll
             Zoomt die Website rein/raus.

     webview Ctrl-0
             Setzt den Zoom auf 100% zurück.

     webview Ctrl-MousePrimary, webview MouseMiddle
             Öffnet den hervorgehobenen Link in einem neuen Tab. (Hinweis:
             Dieses Verhalten kann mit Javascript manipuliert werden)

     any Ctrl-t
             Eröffnet einen neuen Tab in einer neuen Sitzung (ähnlich wie der
             "Neuer Tab"-Knopf)

     browser Ctrl-F4, browser Alt-d
             Schließt den aktuellen Tab

     browser Ctrl-f
             Hebt das Suchfeld hervor

     browser Ctrl-l
             Hebt die Addresszeile hervor

     browser Ctrl-Shift-r / Ctrl-r, browser F5
             Lädt den aktuellen Tab neu (jeweils mit und ohne den Cache zu
             leeren)

     browser Escape
             Bricht das Laden ab

     browser F7
             Aktiviert den Tastaturmodus (Navigation mit dem Textcursor)

     browser F12
             Öffnet die Entwickleroptionen

     browser Ctrl-[ / Ctrl-]
             Zur vorherigen/nächsten Seite im Suchverlauf gehen

     browser Ctrl-p
             Druckt die aktuelle Seite aus. (Eröffnet Dialogfenster)

     any Alt-Left / Alt-Right
             Wechseln zum vorherigen/nächsten Tab

     any F1  Zeigt Informationen über das Programm

     any Alt-n
             n ist eine Zahl. Wechseln zum Tab n. 0 wechselt zum letzten Tab.

   STANDARDTASTENKOMBINATIONEN
     Im Folgenden befindet sich eine unvollständige Liste mit standartmäßigen
     Webkit-/GTK-Tastenkombinationen:

     any Ctrl-PageUp / Ctrl-PageDown
             Wechseln zum vorherigen/nächsten Tab

     search Ctrl-g / Ctrl-Shift-g
             Zum nächsten/vorherigen Suchtreffer gehen

     search Escape
             Bricht die Suche ab

     textarea Ctrl-;
             Emoji einfügen😚️

UMGEBUNGSVARIABLEN
     BADWOLF_L10N
             Eine mit Doppelpunkten getrennte List im Format sprache_LAND wo
             die sprache ISO-639 und das LAND ISO-3166 ist. Z.B.:
             BADWOLF_L10N="en_GB:fr_FR:de_DE".  Wenn diese Variable nicht
             gesetzt ist, gibt es keine Rechtschreibprüfung. Der Variablenname
             könnte in der Zukunft durch einen generischeren ersetzt werden.

             Um eine List mit installierten Sprächen zu bekommen, muss
             enchant-lsmod-2 -list-dicts ausgeführt werden. Bei Versionen vor
             enchant 2.0: enchant-lsmod -list-dicts

DATEIEN
     Die im Folgenden aufgelistetene Pfade benutzen sh(1) -Syntaxe, um der
     XDG-Base-Directory-Specifation gerecht zu werden. Du kannst den Befehl
     echo(1) benutzen, um zu gucken, wo das auf dem Computer ist.

     ${XDG_CONFIG_HOME:-$HOME/.config}/badwolf/content-filters.json
             WebKit-spezifischer Inhaltsfilter-Datei, mit der unerwünschte
             Inhalte (z.B. Werbung, Schadsoftware, ...) geblockt werden
             können. Für mehr Informationen, siehe:
             https://webkit.org/blog/3476/content-blockers-first-look/
             https://webkit.org/blog/4062/targeting-domains-with-content-blockers/
             https://developer.apple.com/documentation/safariservices/creating_a_content_blocker

             Es gibt einen Übersetzer, der AdblockPlus-Filterlisten in Webkit-
             Blocklisten übersetzen kann:
             https://gitlab.com/eyeo/adblockplus/abp2blocklist

             Für eine fertige Datei (die regelmäßig aktualisiert werden
             sollte), siehe:
             https://easylist-downloads.adblockplus.org/easylist_min_content_blocker.json
     ${XDG_CACHE_HOME:-$HOME/.cache}/badwolf/filters
             Hier werden kompilierte Filter gespeichert. Diese Dateien werden
             automatisch generiert und sollten deswegen nicht bearbeitet
             werden. Diese Datei wird hier überhaupt nur dokumentiert, damit
             sie in Sandboxen/Zugriffskontrollen eingearbeitet werden kann.
     ${XDG_DATA_HOME:-$HOME/.local/share}/badwolf/bookmarks.xbel
             XBEL (XML Bookmark Exchange Language) Datei, wird momentan
             unterstützt von: elinks(1), konqueror(1), kbookmarkeditor(1).

             Du kannst einfach eine Verknüpfung zu deren Dateien erstellen,
             aber vielleicht möchtest du lieber XInclude:
             https://www.w3.org/TR/xinclude/ benutzen, welches von badwolf
             systemeigen unterstützt wird und mehrer XBEL-Dateien
             zusammenfügt.

             Außerdem werden die Lesezeicheneinträge nicht neusortiert,
             deswegen ist es eventuell gewünscht, die am häufigsten genutzen
             Einträge an den Anfang der Datei zu schieben.

             Für weitere Informationen über dieses Format siehe:
             http://pyxml.sourceforge.net/topics/xbel/

             Für eine Beispiel-XBEL-Datei siehe:
             https://hacktivis.me/bookmarks.xbel
     ${XDG_DATA_HOME:-$HOME/.local/share}/badwolf/webkit-web-extension/
             Verzeichnis mit den WebKitWebExtensions:
             https://webkitgtk.org/reference/webkit2gtk/stable/WebKitWebExtension.html
             die in geladen werden sollen. Hinweis: dabei nicht um
             Javascript-basierte Erweitungen wie man sie von Firefox oder
             Chrome kennt, sondern um systemeigenen Code aus Shared Objects
             der WebKitGTK API.

             Für Beispiele nützlicher Erweiterungen siehe:
             https://hacktivis.me/git/badwolf-extensions
     ${DATADIR:-/usr/local/share}/badwolf/interface.css
     ${XDG_DATA_HOME:-$HOME/.local/share}/badwolf/interface.css
             CSS-Dateien (jeweils System und User-Ebene), um das Aussehen das
             Interfaces anzupassen. Siehe
             https://docs.gtk.org/gtk3/css-properties.html für die zur
             Verfügung stehen Eigenschaften.

             Für das Austesten eines Aussehens ist es zu empfehlen die
             Umgebungsvariable GTK_DEBUG=interactive biem Start zu setzen und
             dann in den CSS tab zu gehen.
     ${XDG_DATA_HOME:-$HOME/.local/share}/badwolf/scripts/
             Verzeichnis, welches die JavaScript-Userscripts enthält
             (Dateiendung .js), die am Start des Ladens jeder Seite ausgeführt
             werden und sich auch in iframes verschachteln. Nützlich um
             Website-Verhalten zu manipulieren oder fehlende Funktionen zu
             ergänzen.

             Es ist anzumerken, dass — anders als bei GreaseMonkey-artigen
             Userscripts — die badwolf -Userscripts immer ausgeführt werden,
             unabhängig von Hostname/URLs.
