NAME
     wmmaiload-config - Configuration window for wmmaiload dockapp

SYNOPSIS
     wmmaiload-config [options]

DESCRIPTION
     This manual page documents briefly the wmmaiload-config and bar commands.
     This manual page was written for the Debian distribution because the
     original program does not have a manual page.

     wmmaiload-config is a graphical configuration utility for the wmmaiload
     dockapp.

OPTIONS
     A summary of options is included below.

     -h     Short usage help.

     -v     Show version.

     -f filename
            Edit filename.

SEE ALSO
     wmmaiload(1).
