NAME
     "bitly_url" - Command-line interface to WWW::Shorten::Bitly

SYNOPSIS
         bitly_url http://google.com

         bitly_url http://google.com http://www.youtube.com

DESCRIPTION
     bitly_url shortens URLS supplied on the command-line.  You have to setup
     a ".bitly" config file to use it.
