NAME
     lpod_test - ODF::lpOD installation test

USAGE
     lpod_test <filename>

SYNOPSIS
     Sample script that displays a basic information about the current
     ODF::lpOD installation.

     A sample ODF text document is generated if a filename is provided as
     argument.
