NAME
     xtxf


SYNOPSIS
     xtxf [OPTIONS] [SUBCOMMAND...]


DESCRIPTION
     2D matrix screensaver.

ARGUMENTS
   COMMANDS
     version: Show the 'xtxf' version.


   OPTIONS
     color: [-c,--color "color_val (string)"]:
       Set the output color (*default, red, green, blue, yellow, magenta).

     style: [-s,--style "style_val (string)"]:
       Set the output style (*default, columns, crypto, grid, blocks, rain).

     mode: [-m,--mode "mode_val (string)"]:
       Symbol mode (*binary, decimal, hexadecimal, textual).

     accents: [-a,--accents "accents_list ([string])"]:
       Enable symbol accentuations (bold, bright, dim, pulse).

     time: [-t,--time "time (u32)"]:
       Set the duration in seconds.

     speed: [-null,--speed "speed_val (string)"]:
       Set the output speed (slow, *normal, fast).

     bare: [-null,--bare "bare_flag (bool)"]:
       Disable opening sequence.

     debug: [-null,--debug "debug_flag (bool)"]:
       Enable debug mode.

     version: [-v,--version "version_flag (bool)"]:
       Show the 'xtxf' version.


EXAMPLES
     xtxf -a -m decimal -s crypto
