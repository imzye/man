NAME
     phpstorm – launch JetBrains PhpStorm Integrated Development Environment

SYNOPSIS
     phpstorm [jvm-args]

DESCRIPTION
     phpstorm starts up the JetBrains PhpStorm Integrated Development
     Environment.

SEE ALSO
     The web site https://www.jetbrains.com/phpstorm/ .
